# 章节对齐模板

用途：

用于在续写前强制核对“上一章写了什么、这一章必须接什么、这一章写完后要把什么稳定交给下一章”，避免前后章节内容不对等、状态漂移、承诺失踪和 AI 混乱。

## 一、上一章结尾状态

- 上一章最后一个有效场景是什么：
- 上一章结尾时主角处于什么状态：
- 上一章结尾时关键配角处于什么状态：
- 上一章结尾时局势最紧的压力是什么：
- 上一章结尾明确抛给下章的问题是什么：

## 二、本章必须承接

- 本章开头必须先接住哪一个动作 / 情绪 / 危机：
- 本章绝不能跳过的承接点：
- 本章必须回应的上章钩子：
- 本章必须保持不变的关系状态：
- 本章允许推进但不能写崩的部分：

## 三、本章对齐检查

- 本章开头和上一章结尾是否能直接拼接：是 / 否
- 如果不能，缺的过桥信息是什么：
- 本章主推进和上一章留下的问题是否属于同一条线：是 / 否
- 如果不是，为什么必须切线：
- 本章新出现的信息是否会冲掉上一章重心：是 / 否

## 四、本章写完后交给下一章什么

- 本章新的结尾状态：
- 本章新抛出的下章问题：
- 本章已经兑现了哪些上章承诺：
- 本章仍未兑现、但允许继续拖延的承诺：
- 下章不能忘记的状态变化：

## 五、AI 混乱高风险点

- 哪个角色最容易前后口吻不一致：
- 哪个情节最容易和上一章轻重失衡：
- 哪条线最容易被下一章突然忘掉：
- 哪个信息如果写错，会导致前后章节不对等：
