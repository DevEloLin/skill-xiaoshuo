# 单章字数控制模板

用途：

用于把“单章不少于 4300 字”从口头要求改成执行约束。这个模板不负责灌水，而是负责把章节功能拆开、分配字数、检查缺口，并规定不达标时该补哪里。

- 本章核心事件是否只有一个：是 / 否

- 本章是否缺少中段升级：是 / 否
- 本章是否缺少结尾余波：是 / 否
- 如果是，本章应先补哪一层：过程 / 阻力 / 反应 / 余波 / 支线反馈 / 非主角推进

## 三、字数分配草案

- 章首与抓手：目标 350 到 600 字
- 第一轮推进：目标 700 到 1000 字
- 中段冲突 / 阻力 / 升级：目标 1200 到 1600 字
- 关键选择 / 情绪兑现：目标 700 到 1000 字
- 结果与余波 / 章尾钩子：目标 600 到 900 字
- 非主角反馈 / 阵营变化 / 关系余震：目标 300 到 600 字

## 五、未达标时优先补哪里

按顺序补，不允许先补废话：

1. 补场景内阻力，而不是补解释
2. 补角色反应和关系变化，而不是补空情绪词
3. 补中段升级，而不是补重复铺垫
4. 补结果后的余波，而不是补总结
5. 补非主角力量反馈，而不是只让主角自言自语

## 六、禁用补字方式

- 重复解释已知设定
- 重复宣布同一种情绪
- 空转对话
- 与本章目标无关的风景抒情
- 把上一章信息换句话再说一遍

## 八、未达标处理

- 如果未达最低字数，默认不能直接交稿
- 必须先说明是章节任务过薄还是生成展开不足
- 然后补足：中段阻力 / 情绪兑现 / 余波 / 非主角推进 / 章尾钩子中的至少一项
