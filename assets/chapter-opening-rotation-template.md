# 章首轮换模板

用途：

用于避免每章都用同一种开头方式。连续连载最容易出现“主角一醒来 / 主角一到场 / 主角一思考 / 主角团队一开会”式重复起手，这个模板用于强制做轮换。

## 二、10 类入口类型定义

| 编号 | 入口类型 | 说明 |
|------|---------|------|
| T1 | **描述起** | 以景物、环境、氛围切入（景必须带局势/危险/秩序崩口） |
| T2 | **对白起** | 以角色对话直接切入（命令/通知/挑衅/求饶/威胁） |
| T3 | **动作起** | 以正在发生的动作切入（破口/失手/追逐） |
| T4 | **命令起** | 以权力指令或任务下达切入 |
| T5 | **判断起** | 以即时判断或决策切入（必须带反讽/代价，禁止平滑总结） |
| T6 | **异常起** | 以不对劲的现象切入（物件/声音/时间/人际） |
| T7 | **后果起** | 以事件余波或残局切入（血迹/缺席/残局） |
| T8 | **压力起** | 以时限或规则逼迫切入（倒计时/期限/规则压顶） |
| T9 | **视角偏移起** | 以非主角视角切入（反派/路人/下属） |
| T10 | **信息差起** | 以读者/角色信息不对称切入（读者先知/误解/真假倒置） |

## 三、本章候选开头类型

补充：

- 同一种开头类型内部，也不要老用同一种句法起手
- 比如都属于“冲突当场”，也可以分别写成对话切入、争吵切入、动作切入、高潮余波切入
- 比如都属于“异常先行”，也可以分别写成景物异样、物件异样、声音异样、关系异样

**规则 4 — 禁止模板感**：
- 删掉人名后首句是否有独立现场感：是 / 否
- 首句能否无损替换到其他章节：是 / 否（应为否）
- 首句是否命中 AI 安全起手句型：是 / 否（应为否）
- 首句放入近 3 章是否像复制手感：是 / 否（应为否）
