# 角色驱动模板（Character Engine）

本模板用于确保剧情由多个角色共同驱动，而不是只靠主角推进、配角围观。

## 本章角色驱动分配

| 角色 | 本章角色功能 | 驱动了什么 | 主动/被动/缺席 |
|------|------------|-----------|--------------|
| 主角 | | | 主动/被动 |
| 角色 B | | | |
| 角色 C | | | |
| 反派/对手 | | | |
| 其他 | | | |

角色功能类型：
- **推进者**：主动发起行动，改变局势
- **阻碍者**：制造阻力，产生冲突
- **揭示者**：带出新信息，改变认知
- **催化者**：逼迫他人做选择
- **镜像者**：通过对比映照主角
- **失控者**：打破计划，制造意外

## 角色驱动规则

### 硬规则

1. **群像或多角色推进章节应检查**是否有非主角角色主动改变局势；主角独处、铺垫或余波章节可不适用，但要有明确章节功能
2. **反派/对手每 3 章至少主动行动 1 次**（不能只在被动防守或等待）
3. **如果角色连续 2 章缺席，必须在第 3 章给出存在感**（哪怕只是被提及其行动后果）
4. **配角的行动必须来自自身目标，不能只是"帮主角"或"挡主角"**

### 预警规则

| 预警类型 | 触发条件 | 处理方式 |
|---------|---------|---------|
| 主角垄断 | 连续 3 章所有推进都由主角发起 | 下一章必须由非主角角色触发核心事件 |
| 配角工具人化 | 某角色连续 3 章只有"反应"无"主动" | 给该角色一次独立行动或独立信息获取 |
| 反派隐身 | 反派连续 4 章无直接或间接行动 | 必须补一次反派动作或其行动后果 |
| 关系停滞 | 两个核心角色间关系连续 3 章无变化 | 必须发生一次关系温度偏移 |

## 使用说明

1. 每章写正文前，先填写角色驱动分配表
2. 如果发现全章只有主角在行动，先修正再写
3. 每 5 章回顾一次"角色驱动历史"，检查是否有人长期工具人化
4. 推力图不必每章都画，但关键章节（冲突升级、关系转折）建议画
