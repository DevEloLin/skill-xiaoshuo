# 去 AI 味诊断模板

用途：

用于在续写、润色、投稿前先诊断文本里的 AI 痕迹，不直接上来就重写，先判断问题属于节奏、解释、口吻、画面还是信息顺序。

## 基本信息

- 题材：
- 投稿平台：起点 / 知乎 / 其他 / 无
- 当前稿件阶段：首章 / 前三章 / 单章 / 多章连读 / 投稿样章
- 本轮目标：去 AI 味 / 强化抓手 / 强化人物区分 / 压缩解释 / 提高现场感
- 本轮最多处理问题数：建议 1 到 3 项

## 先判主症状

从下面选出当前最重的 1 到 3 项，不要全选：

- 平均句太多，节奏太齐
- 解释腔太重，像作者在说明
- 情绪直给，缺少动作和场景承载
- 对白同声，角色口吻难区分
- 段落完整但没现场感，像写后总结
- 修辞偏空，删掉后不影响理解
- 开头太慢，前 300 字没有抓手
- 结尾太平，像收尾总结，不像下一步被推开

## 修订策略

### 本轮只做这些

- 优先删掉：
- 优先补上：
- 坚决不改：剧情结果 / 角色立场 / 世界规则 / 已确认 canon

### 对应修法

- 平均句：改成松紧对比，长句里夹短句，必要时直接断开
- 解释腔：删结论句，补动作句、阻力句、错位反应句
- 情绪直给：删抽象词，改成手势、停顿、物件、环境反馈
- 对白同声：给每个角色保留专属表达习惯、回避点和词汇偏差
- 没现场感：补“谁在做什么、看见什么、被什么打断”
