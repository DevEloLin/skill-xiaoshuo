# 去 AI 味诊断模板

用途：

用于在续写、润色、投稿前先诊断文本里的 AI 痕迹，不直接上来就重写，先判断问题属于节奏、解释、口吻、画面还是信息顺序。

## 基本信息

- 题材：
- 投稿平台：起点 / 知乎 / 其他 / 无
- 当前稿件阶段：首章 / 前三章 / 单章 / 多章连读 / 投稿样章
- 本轮目标：去 AI 味 / 强化抓手 / 强化人物区分 / 压缩解释 / 提高现场感
- 本轮最多处理问题数：建议 1 到 3 项

## 先判主症状

从下面选出当前最重的 1 到 3 项，不要全选：

- 平均句太多，节奏太齐
- 解释腔太重，像作者在说明
- 情绪直给，缺少动作和场景承载
- 对白同声，角色口吻难区分
- 段落完整但没现场感，像写后总结
- 修辞偏空，删掉后不影响理解
- 开头太慢，前 300 字没有抓手
- 结尾太平，像收尾总结，不像下一步被推开
- 场面过度依赖视觉，其他感官几乎缺席
- 段落解释过满，缺少隐形分镜感和焦点推进

## 修订策略

### 本轮只做这些

- 优先删掉：
- 优先补上：
- 坚决不改：剧情结果 / 角色立场 / 世界规则 / 已确认 canon

### 对应修法

- 平均句：改成松紧对比，长句里夹短句，必要时直接断开
- 解释腔：删结论句，补动作句、阻力句、错位反应句
- 情绪直给：删抽象词，改成手势、停顿、物件、环境反馈
- 对白同声：给每个角色保留专属表达习惯、回避点和词汇偏差
- 没现场感：补“谁在做什么、看见什么、被什么打断”
- 感官单薄：优先补最贴近人物处境的一层非视觉感官，不机械堆五感
- 分镜感不足：删总结句，改用焦点切换、动作接力、物件显影、声响推进或后果先行

## 风格保护协议

去 AI 化最大的风险是：把文本修自然了，但作者原本风格也被洗平了。以下协议防止过度修正。

### 风格锚点（修前必填）

在开始去 AI 化之前，先登记本作品的风格特征：

- 叙事语感（例：短促硬朗 / 绵密细腻 / 冷幽默 / 诗性跳跃）：
- 标志性句法（例：大量短句断句 / 长复合句 / 口语化碎句）：
- 作者偏好词汇（例：特定方言词 / 特定比喻体系 / 角色专属用语）：
- 情绪表达方式（例：克制冷写 / 情绪外露 / 通过物件传达）：

### 禁删特征

以下特征即使看起来"不够自然"也**不允许修掉**：

| 特征 | 说明 |
|------|------|
| 角色缺陷表达 | 角色的口吻毛病（碎嘴、重复、口头禅、语法错误）是人设，不是 AI 痕迹 |
| 作者标志性句式 | 如果作者一贯用某种不规则句式，这是风格不是错误 |
| 有意的粗粝感 | 断句、不完整句、脏话、失控段落，如果服务于情绪爆点则保留 |
| 非标准比喻 | 不套话的比喻即使不优美也比套话比喻好，不要替换成"更标准"的版本 |
| 节奏毛边 | 偶尔的长段或偶尔的极短段，如果是有意的节奏设计则保留 |

### 允许保留的毛边类型

- 角色说话不体面、不完整、不理性 → 保留（人设）
- 叙述中偶尔的主观判断句 → 如果是 POV 角色视角则保留
- 段落间偶尔的跳跃 → 如果是叙事节奏设计则保留
- 不常见的词汇选择 → 如果是作者/角色特色则保留

### 去 AI 化验收

修完后，用以下 3 个问题自检：

1. **风格还在吗**：修后的文本读起来是否还像同一个作者写的？
2. **角色还在吗**：修后的对白是否还保留了角色的口吻缺陷和偏差？
3. **是不是变成了"标准自然稿"**：如果所有章节修完后读起来语感一致、没有波动，说明修过头了

如果 3 个问题中任何一个答案是"不"或"是"（第 3 个），需要回退部分修改。
