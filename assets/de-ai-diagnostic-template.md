# 去 AI 味诊断模板

用途：

用于在续写、润色、投稿前先诊断文本里的 AI 痕迹，不直接上来就重写，先判断问题属于节奏、解释、口吻、画面还是信息顺序。

## 基本信息

- 题材：
- 投稿平台：起点 / 知乎 / 其他 / 无
- 当前稿件阶段：首章 / 前三章 / 单章 / 多章连读 / 投稿样章
- 本轮目标：去 AI 味 / 强化抓手 / 强化人物区分 / 压缩解释 / 提高现场感
- 本轮最多处理问题数：建议 1 到 3 项

## 先判主症状

从下面选出当前最重的 1 到 3 项，不要全选：

**表面症状（词句级）**：
- 平均句太多，节奏太齐
- 解释腔太重，像作者在说明
- 情绪直给，缺少动作和场景承载
- 对白同声，角色口吻难区分
- 段落完整但没现场感，像写后总结
- 修辞偏空，删掉后不影响理解
- 开头太慢，前 300 字没有抓手
- 结尾太平，像收尾总结，不像下一步被推开
- 场面过度依赖视觉，其他感官几乎缺席
- 段落解释过满，缺少隐形分镜感和焦点推进

**深层症状（结构级，AI检测工具真正检测的东西）**：
- 🔴 段段有结论——每段最后一句都在总结/升华/收束，像小作文
- 🔴 段长太均匀——几乎每段都是3-5句，像流水线裁出来
- 🔴 因果链太顺——事情发生→马上反应→马上判断→马上行动，没有断裂和延迟
- 🔴 信息密度太匀——每段承载差不多的信息量，没有密段和空段的交替
- 🔴 叙事太线性——严格按时间顺序推进，没有闪回、跳跃、先果后因
- 🔴 用词太安全——动词/修饰词全是高概率安全选项（缓缓/微微/轻轻/淡淡）
- 🔴 连接太规律——段间过渡都靠"然后/接着/随后/于是"，像导航播报
- 🔴 视角太客观——叙述完全中性，没有POV角色的主观偏见渗入环境描写
- 🔴 段落结构太完整——每段都能独立成立，不依赖上下文，像拼图块而非连续画卷

## 深层结构诊断（🚨AI≤5% 核心）

### 6. 段落结构问题

- 有多少段是"主题句→展开→总结"的完整结构（越多越像AI）：
- 有多少段没有结论句（目标≥30%）：
- 有多少段只有1-2句（目标≥10%）：
- 段长标准差是多少（目标≥段均长度40%）：
- 有没有中途被打断/转向的段落：

### 7. 叙事链问题

- 有没有因果断裂处（事件发生后不立即给反应）：
- 有没有反应偏移处（角色反应不是"正确"的情绪）：
- 有没有先果后因/时间微错位：
- 叙述中有没有 POV 角色的主观偏见渗入环境描写：
- 有没有故意遗漏/不解释的信息：

### 8. 词汇概率问题

- "缓缓/微微/轻轻/淡淡/悄然"出现次数：
- "然后/接着/随后/于是"在 500 字内重复出现：
- "走向/看着/说道/感觉到/意识到"作为主要叙述动词的频率：
- 每 800 字内是否有口语碎片/不标准用法：
- 比喻是否全部使用"像/仿佛/宛如"模板：

### 9. 信息密度问题

- 全章信息密度是否均匀（每段承载差不多信息量）：
- 有没有"大事小写"（重要事件一笔带过）：
- 有没有连续 ≥3 段都在解释/交代：
- 信息释放方式是否单一（全靠对话/全靠叙述）：

### 10. 纹理问题（🚨人类读者一眼识别AI的核心）

- 🔴 角色反应太高效——发现→震惊→接受→行动一步到位，没有卡壳/说错/否认/废话
- 🔴 修辞密度太匀——每段都有比喻/意象/修辞手法，没有纯动作/纯对话/纯物件的素段
- 🔴 配角太工具化——配角只提供功能信息，没有不推进主线的口头禅/职业惯性/偏见/多嘴
- 🔴 信息揭示太顺——线索→正确理解→推进，没有理解错/信息不完整/试错/走弯路
- 🔴 金句太密——每章都在制造可截图金句，连续段落都有设计感明显的句子

诊断方法：
- 角色毛边数（卡壳/说错/否认/废话/笨拙反应）：{N}处（目标≥2处）
- 素段占比（零修辞段/总段数）：{X}%（目标≥20%）
- 配角有真实个性（不推进主线的细节）：有/无
- 信息弯路数（理解错/试错/走弯路）：{N}处（目标≥1处）
- 可摘抄句密度：{N}句/章（按章节功能诊断；出现密集堆放时再检查间隔与自然性）

## 修订策略

### 本轮只做这些

- 优先删掉：
- 优先补上：
- 坚决不改：剧情结果 / 角色立场 / 世界规则 / 已确认 canon

### 对应修法

- 平均句：改成松紧对比，长句里夹短句，必要时直接断开
- 解释腔：删结论句，补动作句、阻力句、错位反应句
- 情绪直给：删抽象词，改成手势、停顿、物件、环境反馈
- 对白同声：给每个角色保留专属表达习惯、回避点和词汇偏差
- 没现场感：补“谁在做什么、看见什么、被什么打断”
- 感官单薄：优先补最贴近人物处境的一层非视觉感官，不机械堆五感
- 分镜感不足：删总结句，改用焦点切换、动作接力、物件显影、声响推进或后果先行

## 风格保护协议

去 AI 化最大的风险是：把文本修自然了，但作者原本风格也被洗平了。以下协议防止过度修正。

### 风格锚点（修前必填）

在开始去 AI 化之前，先登记本作品的风格特征：

- 叙事语感（例：短促硬朗 / 绵密细腻 / 冷幽默 / 诗性跳跃）：
- 标志性句法（例：大量短句断句 / 长复合句 / 口语化碎句）：
- 作者偏好词汇（例：特定方言词 / 特定比喻体系 / 角色专属用语）：
- 情绪表达方式（例：克制冷写 / 情绪外露 / 通过物件传达）：

### 禁删特征

以下特征即使看起来"不够自然"也**不允许修掉**：

| 特征 | 说明 |
|------|------|
| 角色缺陷表达 | 角色的口吻毛病（碎嘴、重复、口头禅、语法错误）是人设，不是 AI 痕迹 |
| 作者标志性句式 | 如果作者一贯用某种不规则句式，这是风格不是错误 |
| 有意的粗粝感 | 断句、不完整句、脏话、失控段落，如果服务于情绪爆点则保留 |
| 非标准比喻 | 不套话的比喻即使不优美也比套话比喻好，不要替换成"更标准"的版本 |
| 节奏毛边 | 偶尔的长段或偶尔的极短段，如果是有意的节奏设计则保留 |

### 允许保留的毛边类型

- 角色说话不体面、不完整、不理性 → 保留（人设）
- 叙述中偶尔的主观判断句 → 如果是 POV 角色视角则保留
- 段落间偶尔的跳跃 → 如果是叙事节奏设计则保留
- 不常见的词汇选择 → 如果是作者/角色特色则保留

### 去 AI 化验收

修完后，用以下 3 个问题自检：

1. **风格还在吗**：修后的文本读起来是否还像同一个作者写的？
2. **角色还在吗**：修后的对白是否还保留了角色的口吻缺陷和偏差？
3. **是不是变成了"标准自然稿"**：如果所有章节修完后读起来语感一致、没有波动，说明修过头了

如果 3 个问题中任何一个答案是"不"或"是"（第 3 个），需要回退部分修改。
