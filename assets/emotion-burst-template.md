# 情绪爆点模板

用途：

用于设计一章或一段里的情绪爆点，避免全文都“稳、顺、专业”，却没有真正失控、失手、失态、失语的时刻。

- 爆点发生章节：
- 爆点发生位置：章首 / 中段 / 章尾 / 卷尾
- 谁先失控：
- 谁被逼到边缘：
- 这次爆点改变什么：关系 / 认知 / 局势 / 身份 / 代价

- 前面压了多久：
- 压力来源：外部冲突 / 内部创伤 / 误会 / 羞辱 / 累积失望 / 恐惧
- 不能再忍的最后一根针：
- 爆点前角色最明显的压抑动作：

## 三、爆点表现方式

至少选 2 到 4 种，不要只用“他说得很愤怒”：

- 话没说完
- 句子突然变短
- 说错话 / 说重话 / 说漏嘴
- 动作失手
- 身体反应先于判断
- 沉默比说话更狠
- 情绪和逻辑打架
- 出现不体面的反应
