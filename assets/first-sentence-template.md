## 二、常见 AI 化首句病灶

以下句型默认优先怀疑：

- 某种感觉先行：他忽然有一种不祥的预感。
- 抽象氛围先行：空气里弥漫着一种压抑的气息。
- 总结判断先行：他知道，事情已经变得不一样了。
- 平滑说明先行：这是一个再普通不过的夜晚。
- 标准作文起手：清晨的风吹过街道，一切似乎都很平静。
- 心理解释先行：他此刻十分愤怒，却努力让自己保持冷静。

## 四、可选起手方式

优先从可见、可听、可触、可造成后果的东西入手：

- 动作先落地：门刚开一条缝，血先从里面淌了出来。
- 异常先刺入：钟停在三点十七分，再没往前走过。
- 后果先摔脸上：尸体抬走半个时辰，院子里还没人敢说话。
- 声音先闯入：楼下那一下砸门，像是冲着骨头来的。
- 物证先出场：桌上多了一只杯子，杯沿还热。
- 关系先失衡：她今天第一次没接他递来的伞。
- 压力先计时：离城门落锁，只剩一刻钟。
- 错位先发作：全城都在找的人，此刻正坐在主位上喝茶。

## 四点五、首句手法池

首句不要只固定在“动作 / 异常”两三种，允许更宽的手法轮换，但前提仍是不能空。

- 对话起手：直接让一句话撞进来，适合威胁、命令、审讯、通知、求饶、挑衅
- 争吵起手：第一句就让关系失控，适合关系撕裂、立场冲突、误解爆开
- 冲突起手：直接进入追逐、交手、压迫、抓捕、翻桌、破门
- 写景起手：允许，但景必须带局势、情绪或危险，不能只是漂亮背景
- 比喻起手：允许，但比喻必须短、准、能立刻咬住局面，不能发散成抒情作文
- 高潮余波起手：先给爆点后的残局、脏污、静默、伤口、缺席
- 反派起手：先从敌对方或对手视角切入，打断主角默认中心
- 路人起手：用旁观者、传闻接触者、下属、小人物把局势折射出来
- 错位信息起手：读者先知道一点，角色还不知道，形成先手张力
- 物象起手：先给一个反常物件、痕迹、气味、声源，再把人带进场

## 四点六、随机轮换规则

- 首句手法不能连续 2 到 3 章固定一种
- 如果最近两章都偏硬开场，这章允许改成对话 / 写景 / 比喻 / 余波起手
- 如果最近两章都偏静态，这章优先改成冲突 / 争吵 / 动作 / 压力起手
- 如果最近几章都太像“冷硬抓手”，这章允许换成带情绪斜度的软起手，但仍要埋压力
- 随机不等于乱写，必须从本章压力源、视角人物、当前局势里选最合适的一种
- 默认至少准备 2 到 3 个不同手法候选，再定最终首句

- 第一句是否能删掉抽象词后仍成立：是 / 否
- 第一句是否先写结论、再补现场：是 / 否
- 第一句是否可以无损替换到别章：是 / 否
- 第一句是否过于完整、过于会解释：是 / 否
- 第一句是否仍像“模型安全起手句”：是 / 否
- 第一句的手法是否和最近两章过于接近：是 / 否
- 第一句是否只是换壳，实际语气仍和前几章一样：是 / 否
