用途：

用于设计“有标签、记得住、带魅力”的角色，避免角色只有设定，没有钉子点，没有让读者一眼记住的气质与行为。

- 魅力类型：危险感 / 脆弱感 / 嘴硬感 / 反差感 / 可靠感 / 疯感 / 高压感 / 温柔失控 / 其他

- 这个标签如何进入正文：动作 / 对白 / 选择 / 外界评价 / 反复场景
