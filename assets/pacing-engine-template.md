# 节奏控制模板（Pacing Engine）

本模板用于控制章节内部和跨章节的微观节奏，防止"全程一个速度"。

## 本章节奏设计

### 节奏曲线

用 ▁▂▃▅▇ 标记每个场景的张力等级（1-5）：

| 场景 | 张力 | 节奏类型 | 段落密度 |
|------|------|---------|---------|
| S1 | ▁▂▃▅▇ | 行动/反应/过渡/喘息/揭示/爆发 | 长段/短段/混合 |
| S2 | ▁▂▃▅▇ | | |
| S3 | ▁▂▃▅▇ | | |

### 节奏类型说明

| 类型 | 特征 | 段落特点 | 适合场景 |
|------|------|---------|---------|
| **行动** | 高速推进、外部冲突 | 短段、短句、动作密集 | 战斗、追逐、对抗、逃跑 |
| **反应** | 消化后果、内部冲突 | 中段、内心独白、情绪 | 行动后的人物反应 |
| **过渡** | 场景转移、信息衔接 | 短段、交代性 | 时间跳跃、地点转换 |
| **喘息** | 降低张力、补充关系 | 长段、对话、日常 | 大事件后的缓冲 |
| **揭示** | 信息释放、认知变化 | 中段、暗示或突转 | 线索浮现、真相碎片 |
| **爆发** | 极高张力、情绪顶峰 | 碎段、断句、不完整句 | 关系破裂、关键反转、高潮 |

### 节奏规则

1. **不允许连续 3 个同类型场景**：如果连续 3 个都是"行动"，中间必须插入"反应"或"喘息"
2. **章尾张力不能低于章中最高点的 60%**：避免虎头蛇尾
3. **全章必须有至少 1 次节奏变化**：从快到慢，或从慢到快
4. **爆发场景后必须有反应场景**：不能爆完直接跳到下一个行动

| 段落位置 | 节奏 | 句长倾向 | 感官侧重 |
|---------|------|---------|---------|
| 开头 10% | | 短/中/长 | |
| 中前段 | | | |
| 中段转折 | | | |
| 中后段 | | | |
| 结尾 10% | | | |

句长倾向：
- **短句密集**：紧张、行动、爆发
- **中句为主**：叙述、推进、对话
- **长句穿插**：描写、内省、喘息
- **碎句/断句**：极端情绪、失控、冲击

## 使用说明

1. 每章写正文前，先设计节奏曲线
2. 写完后对照检查是否执行了设计
3. 如果写完发现全章节奏平均，优先补一个张力波峰或一个喘息波谷
4. 段落级节奏不必每段都标，但关键转折点必须标注
