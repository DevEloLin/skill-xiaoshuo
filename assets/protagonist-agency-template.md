# 主角主动性追踪表

用途：

用于防止主角连续多章只被动承受、被动解释、被动挨打，逐步滑进“主角存在但不真正推动剧情”的状态。

这不是要求主角每章都赢，而是要求主角至少持续做出主动选择、主动尝试和主动承担后果。

## 一、使用规则

- 每章至少登记一次主角在本章的主导状态
- 主导状态只分三类：主动推进 / 被动应对 / 被迫失手
- 如果连续 3 章都不是“主动推进”，下一章优先补一次主动行动
