# 质量闭环模板（Quality Gate）

本模板用于正文输出后的强制校验。不通过则不交稿，必须回修。

## 写后必检清单

每章正文完成后，逐项检查。标记 ✅ 或 ❌，有 ❌ 则必须回修。

### 第一关：结构完整性

| # | 检查项 | 结果 | 备注 |
|---|--------|------|------|
| 1 | 本章是否有明确的章节目标 | | |
| 2 | 本章是否有至少 1 个外部冲突 | | |
| 3 | 本章是否有至少 1 个内部变化（角色认知/情绪/关系） | | |
| 4 | 结尾是否留下钩子、悬念或未解决压力 | | |
| 5 | 字数是否达到最低要求（4300 字） | | |

### 第二关：连续性

| # | 检查项 | 结果 | 备注 |
|---|--------|------|------|
| 6 | 是否与上一章结尾状态对齐 | | |
| 7 | 是否呼应了最近十章中的至少 1 条旧线 | | |
| 8 | 是否引入了未经说明的重大新设定 | | |
| 9 | 时间线是否连续（无跳跃矛盾） | | |
| 10 | 人物称谓/地名/道具规则是否一致 | | |

### 第三关：场景与节奏

| # | 检查项 | 结果 | 备注 |
|---|--------|------|------|
| 11 | 每个场景是否有独立的进入/退出状态变化 | | |
| 12 | 是否存在空转场景（无冲突、无信息、无变化） | | |
| 13 | 是否有节奏变化（不全是同一速度） | | |
| 14 | 爆发场景后是否有反应或余波 | | |

### 第四关：角色驱动

| # | 检查项 | 结果 | 备注 |
|---|--------|------|------|
| 15 | 是否有非主角角色主动推进局势 | | |
| 16 | 对白是否有声线区分（不同角色说话不一样） | | |
| 17 | 是否存在"为了解释而说话"的工具人对白 | | |

### 第五关：信息控制

| # | 检查项 | 结果 | 备注 |
|---|--------|------|------|
| 18 | 本章是否控制了信息释放量（不超过 2-3 条关键信息） | | |
| 19 | 是否存在信息堆积段（连续 3 段以上解释） | | |
| 20 | 是否制造了至少 1 个新疑问 | | |

### 第六关：文本质量

| # | 检查项 | 结果 | 备注 |
|---|--------|------|------|
| 21 | 是否存在解释腔（用解释代替场景） | | |
| 22 | 是否存在空泛情绪词堆叠 | | |
| 23 | 比喻是否套话化 | | |
| 24 | 章首第一句是否避开了 AI 安全起手 | | |

## 评分与处置

- 24 项全通过：可交稿
- 20-23 项通过：可交稿，标注待优化项
- 16-19 项通过：必须回修最严重的 3 项再交稿
- 15 项以下通过：退回重写，不交稿

## 使用说明

1. 每章正文写完后，必须跑一遍本清单
2. 不允许跳过检查直接交稿
3. 回修最多 2 轮，如果 2 轮后仍有 4 项以上未通过，退回章节卡阶段重新设计
4. 本模板同时适用于正文和润色后的版本
