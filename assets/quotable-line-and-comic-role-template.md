# 金句与功能性有趣角色模板

用途：

用于控制两类容易失衡的东西：

1. 金句完全没有，文本记忆点太弱
2. 角色全都太正、太聪明、太会判断，没有功能性搞笑担当和出丑担当

## 一、金句控制

- 本章 / 本卷是否需要金句：是 / 否
- 金句出现频率：低 / 适中 / 偶发重击
- 金句更适合出现在谁身上：主角 / 配角 / 反派 / 旁观者 / 叙述句
- 金句服务什么：人物钉子 / 关系刺点 / 主题表达 / 情绪爆点 / 嘲讽反击 / 卷尾记忆点
- 禁止问题：为了金句而金句 / 连续堆砌 / 脱离人物口吻 / 脱离当下局势

## 二、主角团有趣角色

- 谁是主角团里最特殊、最犯贱、最会搅气氛的人：
- 他的搞笑方式：嘴贱 / 欠揍 / 爱犯贱 / 反差式正经 / 爱拆台 / 爱顺嘴跑偏 / 其他
- 他为什么不能沦为纯逗哏：
- 他除了搞笑之外，真正能推动什么：
- 他什么时候最容易贡献名场面：
- 他什么时候必须收住，不能破坏情绪：

## 三、反派队伍有趣角色

- 谁是反派队伍里的搞笑担当：
- 他的搞笑来源：嘴硬翻车 / 错判局势 / 自信过头 / 跟班歪楼 / 其他
- 他不能只负责搞笑，还必须承担什么：
- 他最适合怎么出丑：说错话 / 站错队 / 读错气氛 / 误判强弱 / 装狠失败 / 其他

## 四、反派队伍出丑担当

- 谁特别弱、分不清形势、分不清局势：
- 他弱在哪里：脑子慢 / 眼界低 / 胆子小 / 自以为聪明 / 跟风 / 其他
- 他的出丑如何服务剧情，而不是只当小丑：
- 他出丑后会带来什么后果：

## 五、验收

- 金句是否适量，而不是句句都想发光：是 / 否
- 搞笑角色是否仍像活人，而不是插科打诨插件：是 / 否
- 反派队伍的搞笑和出丑是否也在推动局势：是 / 否
- 是否有人负责让主角团气氛活起来：是 / 否
- 是否有人负责让反派队伍也不全是冷硬脸谱：是 / 否
