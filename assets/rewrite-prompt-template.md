适用于正文续写、风格统一、局部改写、降低 AI 味。

```text
正文要求：
1. 保持人物口吻一致
2. 避免解释腔
3. 用具体动作和场景承载情绪
4. 不要长期只靠视觉描写；按需要补入听觉、嗅觉、味觉、痛觉、触感、温度或呼吸感
5. 适度加入隐形分镜感，让焦点、动作、物件、声响和后果自然接力，但不要解释自己在做分镜
6. 结尾保留追更钩子
7. 如果关键信息不足，先列缺口，再给保守版写法
8. 本章开头必须和上一章结尾状态对得上，不能像另起一章的新局面
9. 正文默认不少于 4300 字，优先通过有效场景推进达到 4300 到 5000 字，不靠重复解释凑字数
10. 在正文开始前，先在内部完成字数分配，不把一章写成只够两千字的薄章
11. 如果最低字数是硬约束，未达到前不得以总结句、钩子句或“后续可继续”提前收笔
12. 如果当前章节卡天然过薄，先补中段升级、人物反应、非主角推进或结果余波，再输出完整正文
13. 如果仍不足最低字数，只能补有效场景、有效冲突、有效反应和有效余波，禁止重复解释和空转灌水
14. 如果目标是投稿，优先降低解释腔、平均句和角色同声腔，不要修得过于工整发亮
15. 不要连续复用同一种章首起手方式，尤其避免每章都从主角到场、主角判断或主角团队对话开始
16. 本章第一句至少先给出 2 到 3 种不同手法候选，再选最终版本；允许对话、争吵、写景、比喻或高潮余波起手，但不能只是换壳，必须和前几章拉开气质
17. 如果使用写景或比喻起手，景和比喻必须立刻服务于压力、关系或局势，不能写成抒情作文
18. 如果使用对话或争吵起手，第一句不能只是交代设定，必须先带出关系张力或冲突信息
19. 首句不要形成固定作者腔，最近几章连读时要有明显轮换感和随机感
20. 每章至少让一股非主角力量推进局势，可以是反派、敌对阵营、中立方、旁观者或路人反馈
21. 如果本章存在情绪爆点，允许局部出现不完整句、打断句、短促重复和不体面的反应，不要把爆点修得太圆
22. 不要让所有人都理性、克制、完整地说话；至少让不同角色在爆、碎嘴、冷笑、废话掩饰里各占一层
23. 章节里必须尽早给压力，中段要升级，并至少兑现一次情绪价值，不要只有叙事推进没有读者回报
24. 角色出场不能只有功能，至少有一个场面要把他的标签和魅力钉牢
25. 金句只能适量出现，必须属于人物和局势，不能写成脱离场景的作者金句墙
26. 主角团里允许有一个特别犯贱、特别有趣、会搅气氛的人，但他不能沦为纯搞笑插件，必须也能推动关系或局势
27. 反派队伍里也要有人味层次，允许有搞笑担当和出丑翻车担当，但他们的好笑和翻车必须带来真实后果
28. 写本章前，先核对上一章留下的动作、情绪、危机、关系和问题，这一章至少要明确承接其中的主要一项，不能前后像两份不同提纲
29. 再核对最近十章仍在持续生效的线、关系、代价和压力，这一章至少要让其中一条继续发热，不能把每章都写成重新开局
30. 如果这一章要把重心切到新问题，必须给出旧问题仍然存在、仍在施压、或暂时被压住的证据，不能让旧线无声蒸发
31. 正文输出前，必须先完成一次显式自检；如果答不出“本章呼应了最近十章中的什么”，就先回退补齐章节目标和十章呼应板，不直接硬写正文
32. 如果场面只有视觉信息，优先补一层非视觉感官；但不要机械凑满五感，只补当前人物最会真实感到的那一层
33. 分镜感应靠段落焦点、动作次序、物件显影和声响带动，不要写成讲解版脚本，也不要直接说“镜头转到哪里”
34. 如果最近连续三章主角都不是主动推进，这一章必须补一次明确主动性，否则先停在章节卡层，不直接写正文
35. 如果本章关系要升级，但没满足关系图里登记过的可见动作或代价，就禁止直接升级
36. 如果某条未知已经接近或超过最晚提醒章节，这一章必须至少做一次提醒、偏移、升级或明确延期登记，不能当作没发生过
37. 对白占比的默认黄金区间是 40% 到 50%。如果明显高于 50% 或低于 40%，必须给出章节结构理由，并补足非对白推进层，否则不要输出正文
38. 解释性对白的安全占比默认不得高于 5%。如果关键设定、人物判断、关系变化或世界规则主要靠对白直接讲明，先把信息拆开并转移到行动、冲突、误判、感官细节或后果里，再写正文
39. 如果对白连续承担推进、解释、总结三种功能，且中间缺少动作打断、情绪错位、环境反馈或权力变化，本章视为对白过载；即使总对白占比仍在 40% 到 50%，也要先重做场面结构
```

## 润色模板

```text
你现在是我的小说编辑。

题材：
投稿平台：起点 / 知乎 / 其他 / 无
风格目标：
本次处理重点：降低 AI 味 / 加强画面感 / 强化人物区分 / 压缩解释 / 提升节奏
是否要强化情绪爆点和脏感：是 / 否
是否要强化对白分声线：是 / 否
是否要强化情绪价值 / 冲突频率 / 角色魅力：是 / 否
不可改变项：剧情结果 / 角色立场 / 世界规则 / 关键伏笔

原文：

请输出：
1. 你发现的主要问题
2. 润色后的文本
3. 你做了哪些关键修改
4. 哪些 AI 痕迹还残留，需要下一轮继续处理
5. 哪些地方为了保留情绪毛边，没有继续修圆
6. 哪些角色的对白被刻意拉开了声线
7. 这一版补强了哪些情绪价值、冲突节点和角色魅力点
```

## 使用建议

- 续写前先补充最近剧情和已知设定
- 润色时一次只聚焦一到两个目标，结果更稳定
- 对长篇项目，优先配合连载状态模板一起使用
- 如果是连载文，最好同时附上连载节奏板，避免章节空转
