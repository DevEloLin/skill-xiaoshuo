# 续写与润色 Prompt 模板

适用于正文续写、风格统一、局部改写、降低 AI 味。

```text
目标读者：
叙事视角：
文风关键词：

平台风格：

已确认设定：
已确认 canon：
当前人物状态：
当前时间线位置：
已埋伏笔与待回收线索：

上一章摘要：

本章目标：
本章冲突：

本章第一句候选手法：对话 / 冲突 / 写景 / 比喻 / 争吵 / 高潮余波 / 动作 / 物证 / 声音 / 关系刺点

本章涉及的角色声线分工：谁爆 / 谁碎嘴 / 谁冷笑 / 谁用废话掩饰：

请先用 3 到 5 行说明你对本章功能的理解，再输出正文。
正文要求：
1. 保持人物口吻一致
2. 避免解释腔
3. 用具体动作和场景承载情绪
4. 结尾保留追更钩子
5. 如果关键信息不足，先列缺口，再给保守版写法
6. 正文默认不少于 3100 字，优先通过有效场景推进达到 3200 到 4200 字，不靠重复解释凑字数
7. 在正文开始前，先在内部完成字数分配，不把一章写成只够两千字的薄章
8. 如果最低字数是硬约束，未达到前不得以总结句、钩子句或“后续可继续”提前收笔
9. 如果当前章节卡天然过薄，先补中段升级、人物反应、非主角推进或结果余波，再输出完整正文
10. 如果仍不足最低字数，只能补有效场景、有效冲突、有效反应和有效余波，禁止重复解释和空转灌水
11. 如果目标是投稿，优先降低解释腔、平均句和角色同声腔，不要修得过于工整发亮
12. 不要连续复用同一种章首起手方式，尤其避免每章都从主角到场、主角判断或主角团队对话开始
13. 本章第一句至少先给出 2 到 3 种不同手法候选，再选最终版本；允许对话、争吵、写景、比喻或高潮余波起手，但不能只是换壳，必须和前几章拉开气质
14. 如果使用写景或比喻起手，景和比喻必须立刻服务于压力、关系或局势，不能写成抒情作文
15. 如果使用对话或争吵起手，第一句不能只是交代设定，必须先带出关系张力或冲突信息
16. 首句不要形成固定作者腔，最近几章连读时要有明显轮换感和随机感
17. 每章至少让一股非主角力量推进局势，可以是反派、敌对阵营、中立方、旁观者或路人反馈
18. 如果本章存在情绪爆点，允许局部出现不完整句、打断句、短促重复和不体面的反应，不要把爆点修得太圆
19. 不要让所有人都理性、克制、完整地说话；至少让不同角色在爆、碎嘴、冷笑、废话掩饰里各占一层
20. 章节里必须尽早给压力，中段要升级，并至少兑现一次情绪价值，不要只有叙事推进没有读者回报
21. 角色出场不能只有功能，至少有一个场面要把他的标签和魅力钉牢
22. 金句只能适量出现，必须属于人物和局势，不能写成脱离场景的作者金句墙
23. 主角团里允许有一个特别犯贱、特别有趣、会搅气氛的人，但他不能沦为纯搞笑插件，必须也能推动关系或局势
24. 反派队伍里也要有人味层次，允许有搞笑担当和出丑翻车担当，但他们的好笑和翻车必须带来真实后果
```

## 润色模板

```text
你现在是我的小说编辑。

题材：
投稿平台：起点 / 知乎 / 其他 / 无
风格目标：
本次处理重点：降低 AI 味 / 加强画面感 / 强化人物区分 / 压缩解释 / 提升节奏
是否要强化情绪爆点和脏感：是 / 否
是否要强化对白分声线：是 / 否
是否要强化情绪价值 / 冲突频率 / 角色魅力：是 / 否
不可改变项：剧情结果 / 角色立场 / 世界规则 / 关键伏笔

原文：

请输出：
1. 你发现的主要问题
2. 润色后的文本
3. 你做了哪些关键修改
4. 哪些 AI 痕迹还残留，需要下一轮继续处理
5. 哪些地方为了保留情绪毛边，没有继续修圆
6. 哪些角色的对白被刻意拉开了声线
7. 这一版补强了哪些情绪价值、冲突节点和角色魅力点
```

## 使用建议

- 续写前先补充最近剧情和已知设定
- 润色时一次只聚焦一到两个目标，结果更稳定
- 对长篇项目，优先配合连载状态模板一起使用
- 如果是连载文，最好同时附上连载节奏板，避免章节空转
