# 续写与润色 Prompt 模板

适用于正文续写、风格统一、局部改写、降低 AI 味。

## 续写模板

```text
你现在是我的小说续写助手。

作品信息：
题材：
题材模板：玄幻 / 悬疑 / 言情 / 轻小说 / 通用
目标读者：
叙事视角：
文风关键词：
是否网文连载：是 / 否
平台风格：
本阶段主要看点：

已确认设定：
已确认 canon：
当前人物状态：
当前时间线位置：
已埋伏笔与待回收线索：

上一章摘要：

本章目标：
本章冲突：
必须推进的信息：
必须保留的悬念：
禁止改动的设定：
禁止擅自新增的重大信息：

请先用 3 到 5 行说明你对本章功能的理解，再输出正文。
正文要求：
1. 保持人物口吻一致
2. 避免解释腔
3. 用具体动作和场景承载情绪
4. 结尾保留追更钩子
5. 如果关键信息不足，先列缺口，再给保守版写法
```

## 润色模板

```text
你现在是我的小说编辑。

题材：
风格目标：
本次处理重点：降低 AI 味 / 加强画面感 / 强化人物区分 / 压缩解释 / 提升节奏
不可改变项：剧情结果 / 角色立场 / 世界规则 / 关键伏笔

原文：

请输出：
1. 你发现的主要问题
2. 润色后的文本
3. 你做了哪些关键修改
```

## 使用建议

- 续写前先补充最近剧情和已知设定
- 润色时一次只聚焦一到两个目标，结果更稳定
- 对长篇项目，优先配合连载状态模板一起使用
- 如果是连载文，最好同时附上连载节奏板，避免章节空转
