# 场景骨架模板（Scene Engine）

本模板用于把章节拆成可控的场景单元。每个场景是叙事的最小原子，必须有明确的进入状态、冲突推进和退出状态。

**SSOT 规则**：Scene 骨架是所有输出的唯一真实源。小说正文和剧本都必须从 Scene 骨架正向生成，不允许绕开 Scene 直接写正文或剧本。没有 Scene 骨架的章节不允许进入正文阶段。

- **scene_id 格式**：`CH{章节号}-S{场景序号}`，如 `CH03-S1`、`CH12-S3`。scene_id 是强制字段，不允许留空。
- **场景类型**：行动 / 反应 / 过渡 / 喘息 / 揭示 / 爆发
- **INT/EXT**：内景(INT) / 外景(EXT) / 内外景(INT/EXT)。双轨模式必填，纯小说模式建议填写。

## 场景连接检查

| 检查项 | 通过 |
|--------|------|
| 所有 scene_id 是否已填写且格式正确（CH{章号}-S{序号}） | |
| S1 退出状态是否与 S2 进入状态对齐 | |
| 相邻场景是否存在节奏变化（不允许连续 3 个同类型） | |
| 全章是否至少有 1 个非主角驱动的场景 | |
| 全章是否至少有 1 次明确的信息释放 | |
| 全章场景总字数是否达到最低要求（4300 字） | |
| 最后一个场景是否留下钩子或未解决压力 | |

### 双轨模式追加检查

| 检查项 | 通过 |
|--------|------|
| 每个场景的场景标头（INT/EXT）是否已填写 | |

| 每个场景的对白核心是否已填写 | |

## 使用说明

1. 每章写正文前，必须先填写本模板。没有场景骨架不允许写正文
2. 每个场景必须有 scene_id，格式 `CH{章号}-S{序号}`，不允许留空
3. 场景数量建议 2-5 个，不要超过 6 个
4. 每个场景必须有独立的进入/退出状态变化，不能只是"继续上一段"
5. 如果一个场景没有冲突也没有信息变化，考虑删除或合并
6. 驱动角色不能全章都是主角；如果是，先回退修正
7. 如果用户要求双轨输出（小说 + 剧本），剧本兼容字段为必填
8. 正文和剧本都必须从本模板正向生成，不允许从正文反推剧本或从剧本反推正文
