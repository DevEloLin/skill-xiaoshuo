# 剧本输出模板（Screenplay Output）

本模板用于把场景骨架转换为剧本格式。Scene 骨架是唯一真实源（Single Source of Truth），小说正文和剧本输出都必须从同一份场景骨架正向生成。

**强制前提**：必须先完成 scene-engine-template.md，且每个场景的 scene_id 和剧本兼容字段已填写，才能使用本模板。不允许绕开场景骨架直接写剧本。

## 转换原则

- 小说 = Scene × 扩写（加内心、加描写、加节奏控制）
- 剧本 = Scene × 压缩（只留可拍的、可听的、可演的）
- 两者共享同一 scene_id，结构一一对应，表达层不同

---

## 单场景剧本格式

### 场景 CH__-S1

**scene_id**：CH__-S1（必须与场景骨架中的 scene_id 一致）

**场景标头**（强制，不允许缺省）

```
INT/EXT. 地点名 - 时间（日/夜/黄昏/清晨）
```

格式规则：
- 必须以 INT. / EXT. / INT./EXT. 开头
- 地点名用具体名称，不用模糊描述（"某间房" ✗ → "林家书房" ✓）
- 时间只用：日 / 夜 / 黄昏 / 清晨 / 连续（承接上一场）

**动作描写**（Action）

用现在时、第三人称写角色的可见行为。只写摄影机能拍到的东西。

```
角色名 做了什么。环境中发生了什么。
```

硬规则：
- 每段动作不超过 4 行。超过 4 行必须断段
- 不写内心活动（"他感到恐惧" ✗ → "他的手在发抖" ✓）
- 不写背景说明（"三年前他曾..." ✗ → 通过对白或道具暗示 ✓）
- 不写文学修辞（"月光如水银泻地" ✗ → "月光照进来，地上一道白" ✓）
- 不写镜头语言（"特写"、"推镜"、"蒙太奇"、"画面切到" ✗）
- 不写声音设计（"配乐响起"、"音效" ✗）
- 首次出场的角色名用大写/加粗标记

**对白**（Dialogue）

```
角色名
    （附注：语气/动作，可选，不超过 7 字）
对白内容。
```

硬规则：
- 每句对白必须满足至少一项：推进剧情 / 暴露角色 / 制造冲突 / 释放信息
- 不用对白做背景说明（"你还记得三年前我们..." ✗）
- 不用对白做旁白（"观众们可以看到..." ✗）
- 附注只写简短动作或语气，不超过 7 个字（"低声，不看他" ✓；"他心中涌起一阵复杂的情绪" ✗）
- 不同角色说话方式必须有区分（参照对白声线矩阵）
- 潜台词优先：角色说的和想的应该有差距

**场景目标**：（从场景骨架 scene_id 继承，不允许修改）

**冲突**：（从场景骨架 scene_id 继承，不允许修改）

**状态变化**：进入时 → 退出时（从场景骨架 scene_id 继承，不允许修改）

**钩子**：本场景结尾留下什么未解决的压力

## 剧本 4 禁区（硬规则，违反即退回）

| 禁区 | 检测信号 | 替代方案 |
|------|---------|---------|
| 镜头语言 | 出现"特写/推镜/摇镜/蒙太奇/画面切到" | 用动作描写暗示焦点 |
| 心理描写 | 出现"他感到/他想/他意识到/内心涌起" | 用行为、表情、道具外化 |
| 背景堆砌 | 出现"三年前/曾经/历史上/早在" | 通过对白片段或视觉线索暗示 |
| 文学修辞 | 出现比喻、排比、通感、诗化描写 | 用简洁动作句 |

## 剧本 4 必写（缺一退回）

| 必写 | 验收标准 |
|------|---------|
| 场景标头 | 每个场景有 INT/EXT + 具体地点 + 时间 |
| 可见动作 | 每个场景有至少 1 段动作描写，全部为可拍行为 |
| 推进性对白 | 每句台词满足：推剧情 / 暴露角色 / 制造冲突 / 释放信息（至少一项） |
| 状态变化 | 场景结束时局势与开始不同，且与场景骨架一致 |

## 从场景骨架到剧本的转换规则

| 场景骨架字段 | 转换规则 | 剧本对应 |
|-------------|---------|---------|
| scene_id | 直接继承，不允许修改 | 剧本场景编号 |
| 场景名 + 地点 + 时间 | 转为标准格式 | 场景标头（INT/EXT. 地点 - 时间） |
| 进入状态 | 转为可见行为描写 | 开场动作（角色在做什么/环境什么样） |
| 场景目标 | 直接继承 | 标注在场景底部，指导写作方向 |
| 场景冲突 | 通过动作和对白展现，不解释 | 中段对白冲突 + 动作阻力 |
| 试错/灾变 | 转为可见行动序列 | 中段动作推进 |
| 退出状态 | 转为可见行为变化 | 场景结尾的状态变化 |
| 信息变化 → 读者获得 | 通过对白释放 | 关键对白 |
| 信息变化 → 刻意隐藏 | 通过省略或视觉暗示 | 不说的东西比说的重要 |
| 情绪目标 | 通过动作密度和对白节奏控制 | 段落长度 + 对白频率 |
| 节奏标记 | 快→短动作段/密集对白；慢→长动作段/少对白 | 动作/对白密度 |
| 驱动角色 | 场景中主动发起行动的角色 | 开场和关键动作的发起人 |
| 视觉动作 | 直接进入动作描写 | Action 段落 |
| 对白核心 | 直接进入对白 | Dialogue |
| 场景标头 | 直接使用 | 场景标头 |
| 潜台词 | 指导对白写法（说的 ≠ 想的） | 对白设计依据 |

## 剧本质量检查清单

| # | 检查项 | 通过 |
|---|--------|------|
| 1 | 每个场景 scene_id 与场景骨架一致 | |
| 2 | 每个场景有完整场景标头（INT/EXT + 地点 + 时间） | |
| 3 | 动作描写无内心活动词（感到/想/意识到） | |
| 4 | 动作描写无镜头语言（特写/推镜/蒙太奇） | |
| 5 | 动作描写无文学修辞（比喻/排比/通感） | |
| 6 | 每段动作不超过 4 行 | |
| 7 | 对白无背景说明功能（不把台词当旁白） | |
| 8 | 对白附注不超过 7 字 | |
| 9 | 每句对白满足至少一项功能（推剧情/暴露角色/制造冲突/释放信息） | |
| 10 | 不同角色对白有声线区分 | |
| 11 | 每个场景有状态变化（进入 ≠ 退出） | |
| 12 | 场景目标/冲突/状态变化与场景骨架一致 | |
| 13 | 场景间连续性（上一场退出 = 下一场进入） | |

评分：13/13 直接交稿；10-12 标注待优化；≤9 退回重写。

## 使用说明

1. 必须先完成场景骨架（scene-engine-template.md），包含所有 scene_id 和剧本兼容字段
2. 用本模板逐场景转换为剧本格式，scene_id 一一对应
3. 剧本和小说从同一份场景骨架正向生成，不允许从小说正文反向提取剧本
4. 目标/冲突/状态变化从场景骨架继承，不允许在剧本中修改
5. 写完后过剧本质量检查清单（13 项），不通过则回修
