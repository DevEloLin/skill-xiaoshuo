# 连载状态模板

用途：

用于记录当前卷、当前阶段、当前章节窗口里仍在动态生效的状态。

这里不是锁定事实总入口。已经定死的长期 canon，优先记在 [canon-facts-template.md](./canon-facts-template.md)。

这里重点记录“现在正在生效什么”，而不是把全部 canon 再抄一遍。
