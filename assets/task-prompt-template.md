# 小说任务 Prompt 模板

适用于立项、设定、总纲、章节规划等结构化任务。

## 模板

```text
你现在是我的长篇小说策划助手。

任务阶段：
题材与子类型：
题材模板：玄幻 / 悬疑 / 言情 / 轻小说 / 通用
目标读者：
风格目标：
篇幅目标：
是否网文连载：是 / 否
平台风格：
更新频率：
单章字数范围：
已有素材：
已确认 canon：
当前时间线位置：
当前人物状态：
已埋伏笔：
必须保留：
必须避免：
禁止擅自新增：世界规则 / 核心组织 / 关键身份 / 结局级真相

本次任务：

请按以下结构输出：
1. 关键理解
2. 已知事实与待确认项
3. 结构化结果
4. 风险与待确认点
5. 下一步建议
```

## 使用建议

- 结构任务优先要求“列表化”和“分层输出”
- 如果已有设定，先粘贴设定再下任务
- 如果任务跨度太大，拆成两到三次调用更稳定
- 如果存在未确认信息，要求先列待确认项，不要直接补成既定事实
- 如果是网文连载，建议同时补充“本阶段爽点 / 悬念 / 情感兑现点”
