## 与 timeline / canon / universe-map 的联动

- timeline 中所有事件的"地点"字段必须在本 world-map 区域中存在
- world-map 区域调整 → 自动检查 timeline 涉及该区域的事件是否仍成立 + canon 是否一致
- 多界故事还需在 universe-map 中标注本世界为某节点

## 输出验收清单（FAIL → 门 1 BLOCK）

- [ ] 总览 4 项全部填写（不允许"待定"占位）
- [ ] 核心区域数量 ≥ 题材最低要求
- [ ] 每区域有具体"叙事功能"字段（不能是"待用"）
- [ ] 流动路径至少 2 类已填，禁区必填
- [ ] 地图与剧情对应至少 4 个有效条目
- [ ] 题材特化字段（按本书题材）已填
- [ ] 章节卡 / 场景骨架引用的地点全部在本地图存在
- [ ] world-map 修改时同步更新 canon-facts 与 timeline
