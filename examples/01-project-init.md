# Example 01: 从零开始立项

## 场景

你只有一个模糊想法，想把它收敛成一部能继续写下去的小说项目。

## 推荐模板

- [project-brief-template.md](../assets/project-brief-template.md)
- [worldbuilding-template.md](../assets/worldbuilding-template.md)
- [character-template.md](../assets/character-template.md)
- [outline-template.md](../assets/outline-template.md)

## 示例输入

```text
任务阶段：立项 + 设定 + 总纲
题材与子类型：近未来都市悬疑
题材模板：悬疑
目标读者：青年向
风格目标：冷静、压抑、克制、带社会观察
篇幅目标：中长篇
是否网文连载：否
已有素材：
- 一个能“看见他人死亡前最后十分钟”的女主
- 一起看似自杀、实则牵出城市级实验的案件

必须保留：
- 女主能力有代价
- 案件要和城市治理系统有关

必须避免：
- 开局直接讲清所有真相
- 超能力设定过强

本次任务：
1. 帮我做项目简报
2. 补一个世界观基础版
3. 设计女主和主要对手
4. 输出一个三幕式总纲
```

## 期望输出结构

```text
1. 当前任务目标
2. 关键输入假设
3. 项目简报
4. 世界观基础版
5. 角色设定
6. 三幕式总纲
7. 风险与待确认点
8. 下一步建议
```

## 输出重点

- 先收敛“故事承诺”而不是直接写正文
- 明确能力代价和案件层级
- 给出足够稳定的主角与对手结构
- 总纲只需要到能继续拆章节，不需要一次细化到每章

## 为什么这样设计

这个阶段最怕的问题是“方向很多，但没有固定骨架”。

先做立项和总纲，可以避免后面写了几章才发现：

- 主线不够强
- 能力失控
- 反派太空
- 结局方向不清楚
