# Example 02: 继续写某一章

## 场景

你已经有前文、设定和当前章节目标，现在要继续写第 18 章。

## 示例输入

```text
你现在是我的小说续写助手。

作品信息：
题材：玄幻
题材模板：玄幻
目标读者：男频
叙事视角：第三人称限知
文风关键词：冷厉、克制、压迫感强
是否网文连载：是
平台风格：男频升级流
本阶段主要看点：主角第一次公开反击宗门长老

已确认设定：
- 主角林夜目前是外门弟子
- 他隐藏了第二种灵根
- 宗门正在借试炼清洗异己

已确认 canon：
- 林夜不能在公开场合暴露第二灵根
- 七长老怀疑他，但没有证据
- 苏衡已经暗中与林夜合作

当前人物状态：
- 林夜：重伤未愈，但必须参加试炼终段
- 苏衡：明面中立，暗中提供情报
- 七长老：准备在试炼结果公布前动手

当前时间线位置：
- 外门大比第 3 天夜里

已埋伏笔与待回收线索：
- 试炼谷中被封住的旧阵眼
- 苏衡为何知道禁地地图

上一章摘要：
- 林夜在谷底发现旧阵眼，确定有人借试炼杀人
- 他带伤返回营地，发现外门弟子名单被改动
- 七长老的人开始搜查他住处

本章目标：
- 让林夜确定七长老今晚就会动手
- 推进他和苏衡的临时联盟
- 埋下“旧阵眼可反向利用”的伏笔

本章冲突：
- 林夜必须在隐藏底牌和保命之间做选择

必须推进的信息：
- 七长老的杀意已经从怀疑变成执行

必须保留的悬念：
- 苏衡真正站在哪边

禁止改动的设定：
- 林夜仍不能公开暴露双灵根

禁止擅自新增的重大信息：
- 新力量体系
- 新宗门派系
- 七长老真实身份反转
```

## 期望输出结构

```text
1. 本章功能理解
2. 已知事实与待确认项
3. 正文
4. 本章状态回写建议
```

## 输出重点

- 先确认本章是“危机逼近 + 联盟加深”的功能章
- 正文不能偷塞新设定
- 章尾要留下追更钩子
- 写完后应建议更新章节摘要、时间线和伏笔表

## 为什么这样设计

续写最常见的问题不是文笔，而是：

- 角色突然会了不该会的东西
- 时间线乱掉
- 上一章埋的伏笔下一章忘了

这个输入结构就是为了把这些风险提前锁住。
