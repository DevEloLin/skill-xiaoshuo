# Example 03: 网文连载模式

## 场景

你在写一部女频情感成长向连载，想规划第 27 章，并确保这一章既有推进又有章尾钩子。

## 示例输入

```text
任务阶段：网文连载模式
题材与子类型：都市言情 / 职场成长
题材模板：言情
目标读者：女频
风格目标：细腻、克制、有拉扯感
篇幅目标：长篇连载
是否网文连载：是
平台风格：女频成长向
更新频率：日更
单章字数范围：4300-5000

当前连载状态：
- 当前卷目标：女主从被动执行者转向主动争取项目主导权
- 当前主要看点：男女主合作关系开始失衡，情感张力上升
- 当前最大悬念：男主是否早就知道女主被架空
- 最近三章推进点：
  1. 女主发现项目数据被人为删改
  2. 男主替她挡下高层追责
  3. 女主发现男主和董事会有私下会面

本章目标：
- 女主第一次主动试探男主立场
- 推进项目线，不让本章只有情感拉扯
- 结尾留下“她看到的那份文件到底是什么”作为钩子

必须保留：
- 女主此时还不能完全信任男主
- 男主不能直接解释全部真相

必须避免：
- 全章只靠误会拖延
- 把钩子写成纯情绪宣言
```

## 期望输出结构

```text
1. 本章连载价值判断
2. 章节卡
3. 如需正文，正文开头 500-800 字示例
4. 本章钩子说明
5. 连载节奏板回写建议
```

## 输出重点

- 本章必须同时推进“职场线”和“情感线”
- 章尾钩子必须具体，不是空泛情绪
- 单章要有可追读性，不做空转章节
- 如果当前是前三章，要明确这章埋了什么线、给了什么爽点、出了什么反转
- 如果当前接近第 10 到 15 章，要明确这章如何服务第一阶段高潮

## 为什么这样设计

网文最容易失速的地方，是章节看似很多，但推进很少。

连载模式的输入会强制 Skill 去判断：

- 本章是否有推进
- 本章的看点是什么
- 读者为什么要继续追
