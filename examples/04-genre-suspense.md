# Example 04: 悬疑题材特化

## 场景

你要做一部都市悬疑小说，希望 Skill 不要套用通用写法，而是按悬疑题材去组织谜面、线索和反转。

## 推荐模板

- [genre-xuanyi-template.md](../assets/genre-xuanyi-template.md)
- [worldbuilding-template.md](../assets/worldbuilding-template.md)
- [outline-template.md](../assets/outline-template.md)

## 示例输入

```text
任务阶段：题材特化模式
题材与子类型：都市悬疑 / 社会派推理
题材模板：悬疑
目标读者：青年向
风格目标：冷静、写实、压抑、带调查质感
篇幅目标：中篇
是否网文连载：否

已有素材：
- 一名社区调解员在处理普通失踪案时，发现三起旧案共享同一个“见证人”
- 那个见证人每次都提供关键证词，但身份记录总有漏洞

必须保留：
- 谜底必须能回扣前文线索
- 主角不是职业警察
- 结局要带社会现实意味

必须避免：
- 超自然反转
- 最后一章才空降全部真相

本次任务：
1. 用悬疑模板整理故事核心谜题
2. 输出信息层级：读者知道 / 角色知道 / 作者知道
3. 给我一个四阶段推进总纲
4. 列出至少 6 条可回收线索
```

## 期望输出结构

```text
1. 题材理解
2. 核心谜题定义
3. 信息层级表
4. 四阶段推进总纲
5. 线索清单
6. 风险与待确认点
```

## 输出重点

- 悬疑模板要先定义谜题，再组织剧情
- 线索必须能回收，不能只制造气氛
- 误导必须公平，不能靠隐藏关键信息硬反转

## 为什么这样设计

悬疑类写作最怕“过程像调查，结尾靠作者解释”。

这个示例的重点，是让 Skill 先把谜题结构和信息层级固定下来，再谈正文。
