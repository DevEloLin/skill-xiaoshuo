# 示例 06：对白分声线

这个示例演示如何把“所有人都很理性、很克制”的对白，拆成更像真人的不同声线。

## 示例提问

```text
任务阶段：润色 / 对白分声线
题材：都市悬疑
本次处理重点：不要让所有人都像同一个作者
目标：把当前对白拆成四种层次

请先判断谁适合爆，谁适合碎嘴，谁适合冷笑，谁适合用废话遮掩。
然后只改对白，不改剧情结果。
```

## 偏同声腔原段

```text
“我认为现在的情况已经失控了。”林迟说。

“你说得对，我们必须立刻采取行动。”陈雪说。

“如果继续拖延下去，事情只会朝更糟糕的方向发展。”周鸣说。

“现在争论这些已经没有意义了，我们应该先解决眼前的问题。”顾南说。
```

## 问题判断

1. 四个人都过于完整、理性、会总结。
2. 台词互换后基本都成立。
3. 角色没有口头毛边，也没有情绪缺陷。

## 分声线改法

- 林迟：爆，短句，压不住火。
- 陈雪：冷笑，字少，轻飘飘伤人。
- 周鸣：碎嘴，越紧张越说多。
- 顾南：废话掩饰，明明慌，表面还在找别的话。

## 改后版本

```text
“失控了。”林迟盯着门口，声音一下子压低，“不是快。是已经。”

陈雪看了他一眼，嘴角很浅地扯了一下。
“你居然现在才看出来。”

“不是，我早就说过，早就说过别让他一个人去，你们谁听了？”周鸣一口气顶上来，话越说越快，“现在好了，人找不着，线也断了，咱们还站这儿分析，分析有个屁用。”

顾南把桌上的水拧开又拧紧，没喝。
“先别喊。”他说，“这屋里本来就闷。再说你喊也没用，楼下那帮人又听不见。”
```

## 为什么这一版更像人

1. 林迟不再像在汇报，而像火已经压不住。
2. 陈雪没有长篇表达，用冷淡一句就把压力还回去。
3. 周鸣一急就碎，废字和真情绪一起往外冒。
4. 顾南没有直接说怕，而是拿废话和手上动作去挡。

## 使用要点

1. 不是每个人都要“有文采”，而是每个人都要有缺点。
2. 同一场戏里，最好至少有两种以上明显不同的说话层次。
3. 当台词太工整时，优先问：这人急了以后会怎么难看。
