# 示例 07：情绪价值 + 冲突节奏 + 魅力角色

这个示例演示如何同时提升三件事：

1. 读者的情绪价值
2. 章节里的冲突密度
3. 角色的标签感和魅力记忆点

## 示例提问

```text
任务阶段：卷纲 + 章节规划
题材：都市异能
目标读者：男频
本次重点：高情绪价值 / 高频冲突 / 标签化魅力角色

当前问题：
1. 剧情能推进，但情绪回报不够强
2. 章节有冲突，但中段容易平
3. 角色设定不少，但没有特别能钉住读者的记忆点

请按下面顺序输出：
1. 情绪价值板
2. 冲突节奏板
3. 三个核心角色的魅力角色表
4. 再给出一章章节卡示例
```

## 期望结果

### 1. 情绪价值板

- 先说本卷最值钱的情绪回报是什么
- 再说本章要给哪一下爽、哪一下疼、哪一下拉扯

### 2. 冲突节奏板

- 章首尽快给压力
- 中段必须升级
- 章尾把问题推到下一章

### 3. 角色魅力表

- 每个角色至少有一个一眼能记住的标签
- 每个标签都要配一个最能出魅力的场面
- 每个角色都要有代价，不只是“很强”“很帅”

### 4. 章节卡示例

- 写明本章主情绪价值
- 写明冲突频率目标
- 写明哪一个角色在这章最有魅力，靠什么出钉子点

## 为什么这样设计

很多文本的问题不是单点失误，而是三件事同时偏弱：

- 情绪不够值钱
- 冲突不够密
- 角色不够记得住

把这三块拆开先做，再回到章节卡，产出的稳定性会明显高一些。
