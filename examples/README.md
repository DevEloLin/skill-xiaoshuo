# Examples

这个目录提供 `skill-xiaoshuo` 的示例用法，重点不是展示“唯一正确答案”，而是展示：

- 应该如何组织输入
- Skill 应该如何分阶段输出
- 长篇和连载任务要如何带状态信息
- 题材特化时要如何明确约束

## 当前示例

1. [01-project-init.md](./01-project-init.md)
   从零开始做小说立项、设定和总纲。

2. [02-continue-chapter.md](./02-continue-chapter.md)
   在已有设定和前文摘要的前提下继续写某一章。

3. [03-webnovel-serialization.md](./03-webnovel-serialization.md)
   按网文连载模式规划单章推进和章尾钩子。

4. [04-genre-suspense.md](./04-genre-suspense.md)
   使用悬疑题材模板生成更符合题材预期的设定与章节方案。

## 如何阅读这些示例

每个示例都包含：

- 场景说明
- 推荐使用的模板
- 示例输入
- 期望输出结构
- 为什么这样设计

如果你是第一次使用这个 Skill，建议先看 1 和 2。
如果你主要写连载，看 3。
如果你主要做题材化创作，看 4。
