# Examples

这个目录提供 `skill-xiaoshuo` 的示例用法，重点不是展示“唯一正确答案”，而是展示：

- 应该如何组织输入
- Skill 应该如何分阶段输出
- 长篇和连载任务要如何带状态信息
- 题材特化时要如何明确约束

## 当前示例

1. [01-project-init.md](./01-project-init.md)
   从零开始做小说立项、设定和总纲。

2. [02-continue-chapter.md](./02-continue-chapter.md)
   在已有设定和前文摘要的前提下继续写某一章。

3. [03-webnovel-serialization.md](./03-webnovel-serialization.md)
   按网文连载模式规划单章推进和章尾钩子。

4. [04-genre-suspense.md](./04-genre-suspense.md)
   使用悬疑题材模板生成更符合题材预期的设定与章节方案。

5. [05-de-ai-polish.md](./05-de-ai-polish.md)
   演示如何先诊断 AI 痕迹，再分轮把段落修得更自然、更适合平台投稿。

6. [06-dialogue-voices.md](./06-dialogue-voices.md)
   演示如何把同声腔对白拆成爆、碎嘴、冷笑、废话掩饰等不同声线。

7. [07-emotion-conflict-character.md](./07-emotion-conflict-character.md)
   演示如何同时提升情绪价值、冲突密度和角色魅力记忆点。

8. [08-first-sentence-polish.md](./08-first-sentence-polish.md)
   演示如何专门修正每章第一句的 AI 安全起手腔。

9. [09-length-control.md](./09-length-control.md)
   演示如何修复单章严重缺字，并把最低字数变成硬约束。

## 如何阅读这些示例

每个示例都包含：

- 场景说明
- 推荐使用的模板
- 示例输入
- 期望输出结构
- 为什么这样设计

如果你是第一次使用这个 Skill，建议先看 1 和 2。
如果你主要写连载，看 3。
如果你主要做题材化创作，看 4。
如果你主要想降低 AI 味，看 5。
如果你主要想拉开人物对白，看 6。
如果你主要想提高情绪价值和节奏，看 7。
如果你主要卡在章首第一句，看 8。
如果你主要卡在单章严重缺字，看 9。

如果你需要更多首句手法方向，但不想用死模板，读 [../references/first-sentence-technique-library.md](../references/first-sentence-technique-library.md)。
