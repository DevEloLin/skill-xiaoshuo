# 叙事自然度 13 项诊断 · 计算方法与判定规则

> 本文件是 13 项叙事自然度诊断的量化参考。所有“句长变化率”“段长标准差”“口语碎片密度”“金句间隔”等口径以本文件为准。
> 用途：让模型自评/外审时用统一证据定位病灶。阈值是报警器，不是对第三方 AI 检测器结果的保证，也不得凌驾于场景、人物和题材需要。
> 上层规则定义见 [SKILL.md §门 4 Checklist 分级](../SKILL.md#门-4-checklist-分级) 与 [quality-rubric.md](./quality-rubric.md)。

---

## 零、基础术语定义

为避免歧义，13 项硬检全部基于以下定义：

| 术语 | 定义 |
|------|------|
| **句** | 以 `。`/`！`/`？`/`……`/`——` 任一作为终止符的最小单元；省略号"……"按 1 个终止符算；句中含逗号不分句 |
| **段** | 由空行分隔的文本块；单一连续行也算一段 |
| **句长** | 该句的中文字符数（不含标点、不含英文、不含换行）|
| **段长** | 该段所有句长之和 |
| **正文段** | 不是对话段也不是注释段的叙述段；对话段 = 整段以 `"` 或 `「` 起首 |
| **800 字窗口** | 从某个起点起的连续 800 个中文字符的滑动窗口 |

诊断标记表示：
- ✅ 自然：没有可见病灶，或该风格选择有充分戏剧理由
- ❌ 回修：病灶明确且伤害阅读，定位后修订
- ⚠️ 留意：接近阈值或需结合题材、视角、段落功能判断

## 一、表面层（① - ⑧）

### ① 无平均句

**指标**：同段内句长变化率 ≥ 30%

**计算**：
- 取段内所有句长 `[L1, L2, ..., Ln]`（n ≥ 2，否则该段不参检）
- `变化率 = (max(L) - min(L)) / max(L)`
- `Pass = 变化率 ≥ 0.30`

**附加约束**：禁止连续 5 句的句长两两差 ≤ 3 字（即"句长地板"）

**示例**：
- 段：`他盯着门口。门没开，但他后背先凉了下来。事情已经不在他手里了。` → 句长 [5, 13, 11] → max=13, min=5 → 变化率 = (13-5)/13 = 61.5% ✅
- 段：`他看着门口。心里生出不安。事情正在变化。局面不可控。结局已经注定。` → 句长 [5, 6, 6, 5, 6] → 变化率 = (6-5)/6 = 16.7% ❌

---

### ② 无解释腔

**指标**：禁止"先结论后动作"段落

**判定规则**：段落首句若属于以下结构 → FAIL
- 心理判断式："他意识到 / 她明白 / 他知道 / 她感到 + （结论性短语）"
- 关系总结式："其实他们之间已经……"
- 命运宣告式："这一切注定……"

**计算**：
- 扫描每段首句
- 命中上述模式 → 计数 +1
- `FAIL 阈值 = 全章命中数 ≥ 2`（允许 1 处误判）

**示例**：
- 段首：`她接过他递来的刀，检查了两遍，才慢慢收入鞘里。` → 动作起首 ✅
- 段首：`她其实已经不再信任他了。` → 心理判断起首 ❌

---

### ③ 无抽象情绪堆叠

**指标**：抽象情绪词不作为情绪主要描写手段

**禁用词**（叙述层禁止，对话内角色可用）：
震惊 / 愤怒 / 绝望 / 紧张 / 悲伤 / 痛苦 / 喜悦 / 兴奋 / 焦虑 / 恐惧 / 失望 / 崩溃

**计算**：
- 扫描全章叙述段（排除对话段）
- 抽象情绪词命中数 / 全章字数 × 1000 = `情绪词密度（每千字）`
- `Pass = 密度 ≤ 0.5`（即每 2000 字最多 1 处）

**示例**：
- ❌ "他感到极度愤怒，胸口像是有火焰在燃烧。"（"愤怒"叙述层使用）
- ✅ "他把杯子放回桌上，没放稳，瓷底在木面上磕出一声脆响。"（情绪由动作承载）

---

### ④ 无对白同声

**指标**：≥3 个角色，遮去名字后可辨

**判定流程**：
1. 提取本章所有有名角色的对白
2. 对每个角色至少抽 3 句对白
3. 自评/外审：遮去说话人，能否猜出谁说的
4. `Pass = 至少 3 个角色可辨；任意两角色对白互换后语境不成立`

**辨识维度**（建议各角色至少占 2 项）：
- 直说 / 绕说 / 冷处理 / 讥讽 / 截断
- 身份痕迹（教育、职业、地域、年龄）
- 回避点（有些话不会正面说）
- 口头禅 / 习惯结构

---

### ⑤ 有现场感

**指标**：每个场景必须有"动作 + 环境互动"

**判定规则**：
- 场景 = 由 scene_id 标识的最小叙事单元
- 每场景内必须至少出现：
  - 1 处可见动作（有具体动词，非心理动词）
  - 1 处环境参与（光、声、温度、物件、空气、地面、距离任一）

**计算**：
- `场景 i Pass = (动作数 ≥ 1) AND (环境互动数 ≥ 1)`
- `章节 Pass = 所有场景均 Pass`

---

### ⑥ 不过度工整

**指标**：保留 ≥3 处"粗粝感 / 未说满 / 毛边"

**何谓粗粝感**：
- 段尾不收金句、停在动作上
- 句子未说完（"他想说点什么——"）
- 反应不漂亮（卡壳、说错、重复）
- 词汇有断裂感（"那、那个……不对，是另一个"）

**计算**：
- `Pass = 全章粗粝点 ≥ 3`
- `WARN = 1-2 处`
- `FAIL = 0 处`

---

### ⑦ 情绪有失控

**指标**：高压段允许短句 / 断句 / 不完整句

**判定流程**：
1. 标出本章所有"高压段"（冲突顶点、情绪爆发、生死关头、决断时刻）
2. 检查每个高压段内是否存在：
   - 短句（≤ 5 字）≥ 1
   - 断句或不完整句 ≥ 1
   - 嘴硬 / 失手 / 反问任一 ≥ 1

**计算**：
- `Pass = 至少 1 个高压段满足全部条件`
- 全章无高压段 → 不检该项（标 N/A）

---

### ⑧ 无模板感

**指标**：连续 3 段首句不重复句式

**判定**：
- 提取每段首句
- 句式 = 主语类型（人 / 物 / 时间 / 抽象）+ 谓语类型（动作 / 心理 / 状态 / 描写）
- `Pass = 任意连续 3 段，首句句式至少 2 种不同`
- 全章首句句式总数 ≥ 4

## 二、深层结构（⑨ - ⑫）

### ⑨ 段落思维打破

**三项子标准全部 Pass：**

| 子项 | 计算 | 阈值 |
|------|------|------|
| **无结论段比例** | (无结论句段数 / 总段数) × 100% | ≥ 30% |
| **段长标准差** | std(段长) ≥ 段均长 × 40% | 标准差 ≥ 0.4 × mean |
| **中途转向段** | 段落写到一半被声音 / 动作 / 意外打断、主题被迫偏移 | 全章 ≥ 1 处 |

**段长标准差计算示例**：
- 段长样本 [120, 150, 80, 200, 90] → mean = 128 → std = 46.5 → 比率 = 46.5 / 128 = 36.3% ❌（< 40%）
- 段长样本 [50, 200, 80, 350, 100] → mean = 156 → std = 117 → 比率 = 75% ✅

---

### ⑩ 叙事链非线性

**三项子标准全部 Pass：**

| 子项 | 定义 | 阈值 |
|------|------|------|
| **因果断裂 / 延迟** | 事件发生后不立即写反应；先写不相干细节再绕回 | ≥ 2 处 |
| **反应偏移** | 该哭写笑、该怒写沉默、该紧张写无关动作 | ≥ 1 处 |
| **信息故意遗漏** | 故意不交代某细节让读者自行拼接 | ≥ 1 处 |

---

### ⑪ 词汇去高频化

**四项子标准全部 Pass：**

| 子项 | 计算 | 阈值 |
|------|------|------|
| **禁用修饰词** | "缓缓 / 微微 / 轻轻 / 淡淡 / 静静"叙述层命中数 | = 0 |
| **动词去安全化** | "看 / 走 / 想 / 说"等高频动词占动词总数比例 | ≤ 40% |
| **口语碎片密度** | 叙述层口语碎片（得了 / 压根 / 那玩意儿 / 鬼知道 / 横竖等）数 / 800 字 | ≥ 1 |
| **连接词不重复** | "然后 / 因为 / 所以 / 接着"任一在连续 500 字内 | ≤ 2 次 |

---

### ⑫ 信息密度波动

**四项子标准全部 Pass：**

| 子项 | 定义 | 阈值 |
|------|------|------|
| **密段 + 空段共存** | 密段 = 信息点 ≥ 5 / 段；空段 = 信息点 ≤ 1 / 段 | 各 ≥ 1 |
| **大事小写** | 重大事件用 ≤ 1 句话带过 | ≥ 1 处 |
| **解释段连续上限** | 连续解释段数 | ≤ 2 段 |
| **释放方式多样性** | 信息释放方式（对话 / 物件发现 / 他人反应 / 环境暗示 / 内心倒推等）种数 | ≥ 3 种 |

---

## 三、纹理层（⑬）

### ⑬ 纹理验收

**五项子标准全部 Pass：**

| 子项 | 定义 | 阈值 |
|------|------|------|
| **角色毛边** | 卡壳 / 说错 / 否认 / 废话 任一 | 全章 ≥ 2 处 |
| **素段比例** | 素段 = 零修辞、纯记录动作 / 对话 / 物件的段落 | ≥ 全章段数 × 20% |
| **配角真实个性** | 配角有不推主线的口头禅 / 职业惯性 / 偏见 / 多嘴 | ≥ 1 个配角 |
| **信息弯路** | 主角理解错 / 信息不全 / 试错 / 走弯路修正 | 全章 ≥ 1 处 |
| **金句节制** | 金句总数 ≤ 4 句 且 任意相邻两金句字符间隔 ≥ 800 | 同时满足 |

**金句间隔计算**：
- 标出全章所有候选金句（设计感明显的精句）
- 计算每两个相邻金句之间的字符数
- `Pass = min(间隔) ≥ 800 AND 总数 ≤ 4`

## 四、自评 / 外审操作流程

### 自评（无外部 checker 时）

```
for each 项 in 13项:
  1. 引用本文件对应小节的计算方法
  2. 在正文中找具体证据（引用段落或行号）
  3. 计算 / 比对阈值
  4. 输出：✅/❌/⚠️ + 数值 + 引用证据
  5. 写入 gate-log 的 13 项 Checklist
```

### 外审（使用 GPTZero / 类似工具）

```
1. 上传全文获取 AI 概率
2. 若 AI 概率 ≤ 5% → 整体 PASS，但仍须按本文件 13 项做内审
3. 若 AI 概率 > 5% → BLOCK，按 darwin 棘轮触发自动修复
   优先级：⑨ 段落 → ⑪ 词汇 → ⑩ 叙事链 → ⑫ 信息密度 → ⑬ 纹理 → ① ~ ⑧
```

### 报告格式

```markdown
## 反 AI 13 项硬检报告

### 表面层
- [✅] ① 无平均句：变化率 53%（段 3 句长 [5/13/11]）
- [✅] ② 无解释腔：动作起首段 12/13；解释起首 1 段（段 7）
- ...

### 深层结构
- [✅] ⑨ 段落思维：无结论段 35%（11/31）· std/mean = 47%
- [⚠️] ⑩ 叙事链：因果断裂 1 处（< 2 阈值）→ Round 1 修复
- ...

### 纹理层
- [✅] ⑬ 纹理：毛边 3 处 · 素段 22% · 配角张哥（口头禅"你说是不是"）· 信息弯路 1 处 · 金句 3 句间隔 [950, 820]

### 总判定
- 13 项 Pass: 12/13
- 1 项 WARN: ⑩
- BLOCK 状态：否
- 待修复：⑩ 因果断裂数（1 → 2）
```

## 六、形容词堆砌零容忍专项

> 形容词堆砌常会削弱中文叙事的动作感和准确性。13 项里 ③（无抽象情绪堆叠）和 ⑪（词汇去高频化）已覆盖一部分；本章提供写时与验时的诊断口径，供门 3 #11 与门 4 全文复查使用。

### 7.1 七条量化规则（全部 BLOCK 级）

| # | 规则 | 阈值 | 计算方法 |
|---|------|------|---------|
| **7.1.1** | 同名词修饰上限 | ≤ 2 个 | 任一名词的前置修饰（形容词 + 分词短语 + 数量短语）累计 ≤ 2；超过 → 拆句或换动词 |
| **7.1.2** | 千字形容词总量 | ≤ 30 个 | 叙述层（不含对话）形容词数 / 字数 × 1000 ≤ 30；超过 → 按 7.2 替换原则改写 |
| **7.1.3** | 类比修辞密度 | ≤ 3 处/千字 | "像 / 如 / 宛如 / 仿佛 / 犹如 / 恰似 / 好像 / 类似"叙述层出现数 / 字数 × 1000 ≤ 3 |
| **7.1.4** | 程度副词密度 | ≤ 2 处/千字 | "非常 / 极其 / 十分 / 相当 / 格外 / 异常 / 无比 / 极度"叙述层出现数 / 字数 × 1000 ≤ 2 |
| **7.1.5** | "XX的"链长上限 | ≤ 1 个 | 不允许 `XX的XX的` 双链结构修饰同一名词；命中 → 删一个或换主谓结构 |
| **7.1.6** | 同段重复修饰禁令 | ≤ 1 次 | 同一形容词不得在同段修饰两个不同名词；命中 → 改其中一处 |
| **7.1.7** | 形容词起首段禁令 | ≤ 0 段 | 段首不得以形容词或副词起首（"漆黑的夜里"、"寂静地"）；命中 → 改具体动作 / 物件 / 后果起首 |

**计算示例**：

- 段：「他抬起那双布满血丝的、疲惫的、几近绝望的眼睛。」
  → 修饰"眼睛"的形容词 = 3 个 ❌ 7.1.1 FAIL
  → 修订：「他抬眼，眼白里全是红丝。」（修饰 = 0，靠物件细节承载）

- 全章 4500 字，形容词命中 158 个 → 158/4500×1000 = 35.1 ❌ 7.1.2 FAIL
  → 优先删 7.1.4（程度副词）+ 7.1.3（类比）+ 7.1.5（"XX的"链）

### 7.2 替换原则（删完用什么填）

| 删除对象 | 替换为 | 示例 |
|---------|--------|------|
| 形容词修饰 | 精准动词 | "巨大的压力" → "压力压在膝盖上" |
| 形容词修饰 | 具体物件 | "破败的房间" → "墙皮掉了一片，墙根有爬藤" |
| 形容词修饰 | 身体反应 | "恐惧的他" → "他后背先凉了下来" |
| 形容词修饰 | 环境互动 | "紧张的气氛" → "墙上的钟在走，没人接话" |
| 类比修辞 | 直接动作 | "像被针扎一样的疼" → "他手指猛地抽回去" |

### 7.3 对照示例（堆砌 → 拆解）

| ❌ 堆砌 | ✅ 拆解 |
|---------|---------|
| 巨大的、恐怖的、令人窒息的压力 | 他膝盖先撑不住，手扶住桌沿 |
| 漆黑而寂静的夜里，凄冷的风吹过空旷的街道 | 街上没人。风从巷口拐进来 |
| 她那双美丽的、温柔的、深邃的眼睛 | 她抬眼看了他一下 |
| 巨大无比、令人胆寒的咆哮声 | 一声咆哮。玻璃窗在响 |
| 无尽的、深沉的、压抑的悲伤 | 她把勺子放下又拿起，三次 |
| 一座宏伟壮丽、气势磅礴的古城 | 城门一边挂着褪色的麻布幡 |
| 像被狂暴的野兽撕碎一般的剧烈疼痛 | 他的小腿一抽，没站住 |

### 7.4 自动修复路径（按顺序执行）

```
1. 先扫程度副词（7.1.4）→ 全部删，不替换
2. 再扫类比修辞（7.1.3）→ 保留最强的 30%，其余按 7.2 替换为动作
3. 再扫"XX的"链（7.1.5）→ 删后置一个，或拆成两句
4. 再扫同名词修饰超 2（7.1.1）→ 选最有信息量的 1 个保留，其余按 7.2 替换
5. 复查千字总量（7.1.2）→ 若仍超 30，回到 4 继续
```

## 七、AI 感残留全维扫描（门 4 完稿后）

> 13 项硬检 + §六 形容词专项之外，模型仍可能漏过的 AI 指纹。本节是**完稿后**的全维扫描清单，命中超阈值触发修复。这是把"AI 感"从感性印象变成可量化检查的最后一道防线。

### 8.1 19 项全维信号

**句法层**：

| # | 信号 | 阈值 | 修复方向 |
|---|------|------|---------|
| 8.1.1 | 主语开头段比例 | ≤ 60% | 改用动作 / 物件 / 声音 / 时间起首 |
| 8.1.2 | "他 / 她 / 它"开头句比例 | ≤ 35% | 视角换位、用动词起首、用物件起首 |
| 8.1.3 | 时间状语起首段（此时 / 此刻 / 这时 / 那时 / 突然 / 忽然） | ≤ 2 段/章 | 删时间词，让事件自然推进 |
| 8.1.4 | 排比句（3+ 短句结构同模板） | ≤ 1 处/章 | 拆掉，至少 1 句改为不同结构 |
| 8.1.5 | 对仗 / 对偶句 | ≤ 2 处/章 | 同上 |
| 8.1.6 | 完整句（主谓宾全）比例 | ≤ 75% | 25% 必须是短句、不完整句、对话或动作碎片 |

**词汇层**：

| # | 信号 | 阈值 | 修复方向 |
|---|------|------|---------|

### 8.3 自动修复优先级

```
P0（结构性指纹，必修）：
  → 8.1.4 排比 / 8.1.14 三层比喻 / 8.1.10 量词单调
P1（句法同质，强烈影响 perplexity）：
  → 8.1.1 主语开头比例 → 8.1.2 他她开头 → 8.1.6 完整句比例
P2（修辞过密）：
  → 8.1.16 拟人化 → 8.1.15 如同句 → 8.1.7 XX地
P3（段落同质）：
  → 8.1.11 段尾收束 → 8.1.12 段首景物 → 8.1.13 过渡词
P4（局部修饰）：
  → 8.1.8 了字结尾 → 8.1.9 抽象名词 → 8.1.18 的地得密度
```

每轮只攻一个 P 级，攻完再扫整章重测。
