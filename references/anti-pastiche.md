# 反拼贴规则

目标：

把“吸收热门作品长板”约束成可执行规则，避免作品最后变成设定拼盘、桥段拼盘、人物拼盘和气质拼盘。

这份规则不讨论“像不像某部作品”，而讨论一件更实用的事：

- 你的小说是否有统一主体验
- 所有优点是否都服务同一套主线与世界逻辑
- 读者看到的是否是一个完整作品，而不是若干热门写法的机械拼装

## 一、什么叫拼贴

当一部作品出现以下情况时，就已经进入拼贴风险：

- 世界观来源很多，但没有统一底层规律
- 爽点很多，但每一类爽点都像来自不同书
- 角色很多，但说话方式、命运功能、出场作用高度借影
- 前期像悬疑，中期像热血群像，后期突然变成宿命史诗，但中间没有自然过桥
- 设定能单独成立，组合起来却互相打架
- 读者能感受到“这里像 A，那里像 B”，却感受不到“这就是你的书”

拼贴最大的问题不是“借鉴太多”，而是：

- 作品没有统一核心问题
- 主长板和辅长板没有主从关系
- 所有好东西只是堆在一起，没有经过再组织

## 二、反拼贴总原则

### 1. 先有主体验，再选长板

先回答：

- 这本书最核心的阅读体验是什么
- 读者追这本书，到底是在追什么
- 最终是想让读者记住人物、谜团、升级、棋盘、宿命，还是世界厚度

只有先确定主体验，后续所有长板才有挂载点。

### 2. 主长板最多 1 到 2 项，辅长板最多 2 到 4 项

不要同时把“世界厚度、升级爽点、信息悬疑、史诗宿命、少年热血、情绪爆点、群像、仪式感、克制成长、文明考古”全部当主轴。

推荐做法：

- 主长板：决定作品骨架
- 辅长板：负责增强表现力
- 气质长板：只负责修饰，不负责改骨架

### 3. 所有长板必须回落到同一套载体里

如果一个长板没有落到结构载体里，它就只是口号。

对应关系建议：

- 世界厚度 -> 宇宙设定、世界规律、地图体系
- 信息悬疑 -> 信息层级、伏笔矩阵、章节信息差
- 升级爽点 -> 阶段目标、阻力、兑现节点
- 群像辨识度 -> 角色卡、关系网、势力棋盘
- 史诗宿命感 -> 终局命题、远回收伏笔、时代冲突
- 少年热血感 -> 人物关系、牺牲节点、章尾情绪抬升

### 4. 任何借鉴都必须被“本书主线”重写一遍

借来的只能是机制，不能是现成模块。

必须经过三次转换：

1. 转成你的主线目标
2. 转成你的世界规则与地图逻辑
3. 转成你的角色关系与人物代价

如果一个优点不能被这三层重写，就不要直接接入。

## 三、禁止事项

以下行为视为高风险拼贴，默认禁止：

### 1. 禁止直接复刻标志性组合

不能复制：

- 标志性的力量体系组合
- 标志性的世界分层结构组合
- 标志性的角色关系三角或群像功能分配
- 标志性的“成长路径 + 身份揭示 + 终局命题”成套组合

单个机制可以抽象，但成套组合不能照搬。

### 2. 禁止只复制味道词，不补因果系统

例如只说：

- 要有史诗感
- 要有宿命感
- 要有克制感
- 要有诡秘感

如果没有把这些词落到规则、人物、代价、伏笔、信息差里，就只是表层贴皮。

### 3. 禁止为了“像热门”而频繁换作品气质

一本书的叙事气质必须有主轴。

可以局部换挡，但不能：

- 前 20 章靠高概念爆点
- 20 到 60 章突然改成慢热考据
- 60 章后又突然变成纯爽文冲榜节奏

除非你的结构里本来就设计了明确的阶段变奏，并且这些变奏被人物成长和世界升级自然承接。

### 4. 禁止把配角当“热门角色功能件”拼进去

不能因为某类角色受欢迎，就机械加入：

- 冷面强者导师
- 嘴碎搞笑搭档
- 天降神秘少女
- 命运对照组宿敌

角色必须回答三个问题：

- 他在这本书里推动什么局面
- 他改变主角什么认知或命运
- 如果删掉他，会不会伤到主线结构

如果回答不了，就说明是装饰性拼件。

## 四、执行流程

当你准备“吸收热门作品长板”时，按这个流程处理：

### 第一步：先定义本书主体验

只允许写一句主定义：

- 这是一个怎样的故事
- 读者最稳定能获得什么体验

例如：

- 一个以资源匮乏和长期代价驱动的克制成长玄幻
- 一个以信息差、仪式感和逐层揭谜推动的悬疑冒险长篇
- 一个以大棋盘、文明遗产和宿命回响构成的史诗群像长篇

### 第二步：列主长板和辅长板

格式建议：

- 主长板：1 到 2 项
- 辅长板：2 到 4 项
- 明确舍弃：至少 2 项

“明确舍弃”很重要，它能防止你什么都想要。

### 第三步：给每个长板指定唯一载体

示例：

- 信息悬疑 -> 伏笔矩阵 + 章节卡信息差
- 世界厚度 -> 世界地图 + 文明史
- 群像辨识度 -> 势力棋盘 + 角色关系表

如果一个长板找不到载体，不进入当前版本。

### 第四步：检查是否冲突

至少检查以下四类冲突：

- 节奏冲突：慢热世界厚度是否被高频爆点打断
- 规则冲突：悬疑保密是否被爽点提前透支
- 人物冲突：群像空间是否被单主角冲榜节奏挤压
- 终局冲突：当前卖点是否会削弱终局高度

### 第五步：做一次“删减测试”

对所有辅长板问一遍：

- 删掉它，这本书核心还在不在
- 留下它，它有没有真正增强主长板

没有增强主长板的辅长板，删除。

## 五、验收标准

满足以下条件，才算通过反拼贴验收：

1. 能用一句话说清作品主体验
2. 能明确区分主长板、辅长板、舍弃项
3. 每个保留长板都有对应模板或结构载体
4. 所有保留长板都服务同一条主线和同一套世界逻辑
5. 角色、设定、伏笔、地图之间没有明显的“借影拼接感”
6. 删掉具体参考作品名，这套方案依然自洽成立

如果第 6 条做不到，说明还停留在“像某几本书的混合体”，不是你自己的作品。

## 六、常见错误与修正

### 错误 1：想把所有长板都做成主轴

修正：

- 把主长板压缩到 1 到 2 项
- 其余改成辅助表达层

### 错误 2：只会写气质词，不会写结构载体

修正：

- 每个长板必须绑定模板、文档或章节机制

### 错误 3：一边想慢热厚重，一边又要求每章都极限爆点

修正：

- 把爆点改成阶段性波峰
- 把高频刺激让位给长期回响

### 错误 4：人物关系像热门角色功能复用

修正：

- 重写角色的利益、伤口、命题和作用点
- 让人物从本书世界规则里长出来

## 八、最终判断句

当你犹豫某个灵感要不要接入时，用这句话判断：

“它是在强化我的书，还是在把别人的书零件接到我的书上？”

如果更接近后者，就不要用。
