# 角色身份树、群像独立线与命名协议

> 适用：创建主角、核心配角、群像、势力人物，或为小说起名时。目标不是堆“人设”，而是让每个重要人物拥有自己的过去、选择、代价、声音与命运分支。

## 1. 角色层级：独特，不等于人人一部长篇

按叙事影响分层，避免把群像写成拥挤名单：

| 层级 | 最低要求 | 不应承担 |
|---|---|---|
| 核心角色 | 完整独立事件线、不可逆选择、代价、关系弧、独有声线与命名逻辑 | 只替主角解释或赞叹 |
| 重要角色 | 私人目标、至少一次独立行动/失误、与主线的交汇和后果 | 只在需要工具时出现 |
| 阶段角色 | 一个清晰欲望或立场、一项能被记住的选择/细节、明确退场或转位 | 假装拥有未兑现的大弧光 |
| 路人/功能位 | 准确的社会位置、一个具体反应或局部利益 | 强行补完整悲剧史 |

“所有角色都有自己的故事”指每个已命名、反复出现的人都能说明**他在主角镜头外为何而活**；不等于每个人都抢主线。

## 2. 角色独有性的六个锚点

核心与重要角色必须拥有以下六项，内容不可与另一核心角色重复：

1. **私人问题**：若主线不存在，他仍想解决什么？
2. **旧伤与保护性谎言**：他因何事学会现在的错误活法？
3. **压力选择**：同一危机下，他会优先保住什么，又愿意牺牲什么？
4. **独立事件线**：起因 → 自主行动 → 反噬/代价 → 与主线交汇或分叉。
5. **表达与身体习惯**：声线、停顿、动作、审美或处理麻烦的方式；必须源自经历，不是标签拼贴。
6. **命名坐标**：名字、称呼、别名和禁称分别透露什么身份、关系或认知边界？

两人若能互换其中四项以上，就不是两个角色；合并、重铸或删去其中一人。

## 3. 角色身份树

在 `02-characters/character-identity-tree.md` 建立一棵“关系与命运树”，不是血缘名单。

```
根：作品的中心命题 / 世界的核心裂缝
├── 主干 A：主角为此命题付出的选择
│   ├── 枝 A1：盟友以另一种代价回应
│   └── 枝 A2：亲密关系的误解、背离或守护
├── 主干 B：敌对方/另一势力对此命题的解决方案
│   └── 枝 B1：执行者的私人欲望，与上层目标并不完全一致
└── 主干 C：普通人或中立方承担的现实后果
```

- **根**只写作品真正反复追问的问题，例如“秩序是否值得用亲密关系交换”。
- **主干**是不同阵营或关系对根问题的回答；每条主干至少有一个主动选择和一个代价。
- **枝**是人物自己的事件线。枝可汇回主干、折断、移植到另一阵营，不能永远悬空。
- 角色不是“主角树的叶子”而已：敌对方、中立者、小人物均可拥有主干或分枝。

## 4. 群像的独立故事线

每个核心角色须登记一张“私人事件卡”：

`触发事件 → 他自己的目标 → 秘密/误判 → 主动选择 → 付出的代价 → 结果 → 如何改变主线或关系`。

群像的高光不靠轮流发糖，而靠**不同人以不同方法回答同一个难题**。一个角色可以沉默一卷，但他的事件线必须在别处继续运转，并在再次出现时带回变化。

### 场景权利检查

角色在场时，至少占有一种“场景权利”：改变目标、改变信息、改变关系、改变行动方案或承担后果。没有任何场景权利的反复出场角色，多半只是传话筒。

## 5. 起名不是装饰

### 5.1 名字的四层信息

每个核心名字至少明确其中两层：

- **社会层**：时代、地域、阶层、家族/宗派、命名习俗。
- **亲密层**：谁用全名、乳名、字、代号或贬称；称呼改变意味着什么。
- **人物层**：读音、节奏和字形是否贴合人物的气质与人生，而不是直译性剧透。
- **叙事层**：名字是否好记、易读、与同场人物可区分；别名何时揭示才有信息价值。

### 5.2 命名流程

1. 先写命名体系：现实题材遵从地域与代际；历史/古风先定时代与称谓；架空先定语言/阶层规则。
2. 为核心角色建立“声形指纹”：首字、尾音、字数、常用称呼不可大面积撞车。尤其避免同一场景里多个名字同音、同首字或同样生僻。
3. 名字不替人物解释性格。慎用把“冷、夜、雪、殇、龙、凤”等意象批量贴在名字上的做法。
4. 称呼变化必须登记到关系/知识状态：全名、姓氏、职位、绰号、真名、假名各自有使用者、场合和揭示窗口。
5. 新角色入场前做“同场混淆检查”：与已活跃角色在读音、字形、身份标签、声线中至少两项明显不同。

## 6. 五道门接入

- **门 0**：群像或核心人物项目先建身份树、核心私人事件卡和命名体系；仅给零散人物时，先判定层级，不滥建档。
- **门 1**：读取本章出场人物的身份树位置、私人事件线状态、当前称呼/知识边界；确认其出场有场景权利。
- **门 2**：每个重要人物标注本场的自主目标、选择、信息差与状态变化；没有变化的出场必须有情绪、关系或伏笔功能。
- **门 4**：检查人物是否可互换、是否只服务主角、称呼/名字是否混淆或越权、事件线是否长期失联。C2/C3 仍为硬检。
- **门 5**：回写私人事件卡、关系/知识状态、称呼变化、命名账本和身份树枝条的汇流或分叉。

## 7. 常见失败与修复

| 症状 | 修复 |
|---|---|
| 人物都有标签，却没有自己的事 | 补一张私人事件卡；让其作一次主角不希望的选择 |
| 群像只轮流展示高光 | 让角色的选择互相造成后果，而非平均分配戏份 |
| 反派/配角可以互换 | 重新分配压力选择、秘密与代价，或合并角色 |
| 名字像随机古风词库 | 先定命名体系，再重起一组声形分明、称呼有关系意义的名字 |
| 别名只为制造神秘 | 给别名一个社会功能与揭示后的行动后果 |
