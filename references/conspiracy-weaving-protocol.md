# 多层阴谋与布局编织协议

> 适用：用户要求大阴谋套小阴谋、幕后棋局、多重反转、草蛇灰线、权谋/悬疑/谍战/群像长线布局时。本协议把“布局”当作可追踪的因果网，而不是只靠作者保密的谜底。

## 1. 目标与边界

目标是让读者在揭示后能回看见因果：**此前的行动、痕迹、误读和代价都真实存在，只是意义被重新排列。**

- 大阴谋不是万能幕后黑手。它是一个有资源边界、信息盲区、代价与失败风险的终局目标。
- 小阴谋必须能独立成立：即使不知道上层棋局，执行者仍有自己的获益、恐惧或误判。
- 不是每条支线都要隶属总局。保留独立利益、对抗阴谋与偶然余波，棋盘才像真实世界。
- “无数布局”指可持续扩展的登记体系，不是在一章内同时抛出无数谜面。读者同一阶段应只需追踪 1 个主问题、至多 2 个活跃副问题。

当多个伏笔、筛选机制、局与反制需同时运行时，`conspiracy-weave.md` 只管理 J- 阴谋节点；并发关系、人物多重位置与场景交通交由 [并发布局协议](./concurrent-plot-weave-protocol.md) 的 `concurrent-plot-weave.md` 管理。

## 2. 四层局网

用 `conspiracy_id` 与 `parent_id` 管理，不按“套娃次数”硬嵌套：

| 层级 | 名称 | 作用 | 读者可见形态 |
|---|---|---|---|
| L0 | 终局局 / 元目标 | 改写秩序、夺取某物、阻止某结局等 | 前期不可完整说明，只留下结果压力 |
| L1 | 战略局 | 为 L0 服务的阶段性战场，可互相竞争或冲突 | 一个势力行动、政策、战争、交易、仪式 |
| L2 | 执行局 | 角色在当前卷/阶段实际发动的局 | 案件、陷害、招募、夺权、救援、赌局 |
| L3 | 线索与载体 | L0–L2 留下的可观察痕迹 | 物件、证词、习惯、账目、路线、空白、后果 |

每个局至少要回答：谁在行动、他以为自己要什么、他真正服务什么、如何实施、受什么限制、失败会付什么代价、谁能从中反制。缺其中任一项，就不进入正文。

## 3. 节点、边与状态

### 3.1 布局节点必填字段

每个节点使用 `CJ-卷号-序号` 标识，写入 `03-outline/conspiracy-weave.md`：

- `层级 / parent_id / 状态`：L0–L3；没有上级时标为 `independent`，不要伪造从属关系。
- `表面目标 / 真实目标 / 执行者认知`：三者允许不同；“执行者不知道真相”必须写清知道到哪一步。
- `棋手与资源`：行动者、盟友、筹码、时间窗口、权限；禁止全知全能。
- `手段与因果链`：行动 → 直接结果 → 可预见余波 → 上层获益/受损。
- `掩护与可见痕迹`：读者先得到的正常解释，以及之后可成立的真实解释。
- `反制入口`：主角或其他角色可通过何种信息、选择或代价改变局势；不能只等反派自曝。
- `揭示窗口 / 回收方式 / 失败或变形路径`：揭示至少重释两项旧信息，并迫使一次新的选择。

### 3.2 因果边

只允许显式登记这五类边：`资助`、`利用`、`掩护`、`误导`、`反制`。每条边写清方向、证据、何章可被读者验证。一个节点可服务多个上层目标，也可被两个棋手争夺；这比单一树状套娃更能形成交错布局。

### 3.3 生命周期

`草案 → 埋入 → 运行 → 偏移 → 局部揭示 → 反噬/变形 → 回收或休眠`。

- 每个活跃局必须在预设窗口产生一次状态变化：推进、受阻、误判、暴露、反制或变形。
- 局部揭示解决眼前问题，但留下更高层问题；不能只延迟答案。
- 休眠必须有重启条件和最晚复查章；长期不动的节点转为废案或合并，不能无限挂账。

## 4. 线索、公平性与反转

### 4.1 三面线索卡

每条 L3 线索登记：`表层解释 / 可见证据 / 真实解释 / 首埋 / 轻触 / 重释 / 影响的节点`。至少两种不同来源支撑重要揭示（例如物证 + 行为、证词 + 时间线），避免最后一章靠一段解释补完。

### 4.2 合法反转公式

一次重要反转必须同时满足：

1. **旧证据仍为真**：改变的是解释范围、行动者、目的或受益者，不是篡改已发生事实。
2. **新选择有代价**：揭示后立刻改变主角或棋手的可选行动，不能只制造“原来如此”。
3. **限制依旧有效**：角色不因反转突然获得未铺垫能力、情报或资源。
4. **至少一方判断失误**：局会反噬，不能让单一棋手次次算尽。

优先使用：范围扩大、代理人错位、手段与动机分离、计划失败却产生副作用、反制局借原局反向推进。禁止：临时新增规则、死亡/身份无依据翻转、反派全知解释一切、所有巧合都指向同一幕后人。

## 5. 门流程接入

### 门 0 / G 或 R 模式：先建网，再写

建立至少 1 个 L0 或明确标注“无 L0”、2 个可独立行动的 L1/L2 节点、6 条 L3 线索，并登记一条独立局或反制局。先输出局网摘要、节点表、首卷揭示节拍，强制暂停等用户确认。

### 门 1：读取与压力检查

加载局网 HEAD：本卷活跃节点、相邻两层节点、即将到期的揭示窗口、主角已知范围、活跃线索。确认本章至少改变一个节点状态，或明确是为下次变化准备可验证的载体；检查读者活跃问题未超载。

### 门 2：每场景的阴谋字段

涉及局网的场景补齐：`关联 CJ-ID`、`表面冲突`、`真实操作`、`视角人物所知`、`新增/重释痕迹`、`状态变化`、`反制可能`。没有状态变化的“神秘对白”不算布局推进。

### 门 4：布局硬检

以下任一项 FAIL → 回退修复；不能用补一段解释蒙混：

- 已揭示内容能在已写证据和时间线上追溯；无事后改写。
- 每个执行者的行为符合其知识、资源、风险承受与个人动机。
- 本章新谜面有节点归属、可见痕迹与复查窗口；没有“凭空神秘人”。
- 本章至少一方拥有真实反制空间；主角不只是被局推动。
- 活跃节点没有无理由停摆；超期节点已推进、变形、合并或退役。

### 门 5：回写

更新节点状态、因果边、线索三面卡、角色知识范围、揭示窗口与未兑现代价；在 memory-stream 记一条 `conspiracy` delta。只记录变化，不重复整张局网。

## 6. 节奏与容量

- 一卷建议：1 个核心 L0/L1 压力源、2–4 个战略/执行局、6–12 条有归属的线索。可扩展，但新增前必须说明它服务、对抗或扰动哪个既有节点。
- 单章最多新开 1 个读者问题；若新开问题，优先在同章给旧问题一次推进、偏移或局部兑现。
- 每 3–5 章让至少一条线索被重释或一局产生代价；每卷至少一次局部闭环，防止只埋不收。
- 关键揭示遵循“二旧一新”：重释至少两项旧信息，打开一个更高层问题，并改变当下的行动。

## 7. 失败信号与修复

| 信号 | 修复 |
|---|---|
| 所有线都指向同一反派 | 保留至少一条独立利益线或反制线，并给它独立结果 |
| 反派看似无所不能 | 补资源、信息、时间与失败代价；安排一次可追溯的误判 |
| 揭示像作者讲课 | 把解释拆回行动、物证、错判和选择；先让角色用错误解释行动 |
| 谜面越积越多 | 合并同功能节点；先结一个局部局，再开新问题 |
| 主角只被牵着走 | 在下一节点写入可利用的弱点与主动选择，且选择必须有损失 |
