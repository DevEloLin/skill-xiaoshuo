# 去 AI 味改写参考

> 本文用于定位模板感、解释腔、同声对白等自然度问题；不承诺任何第三方检测器分数。13 项诊断（8 表面 + 4 深层 + 1 纹理）贯穿门 1 到门 4，但只在病灶可定位且伤害阅读时回修。
>
> **量化计算口径以 [anti-ai-thresholds.md](./anti-ai-thresholds.md) 为 SSOT**。本文是"病灶 + 修法"参考；阈值数字不一致时以 SSOT 为准。

目标：

把”知道有 AI 味”进一步变成”知道该怎么改”。这份参考不讲抽象理念，只讲常见病灶和对应修法。

补充：

如果最重的问题集中在每章第一句，不要泛泛重写整段，优先单独处理章首第一句。可搭配 [章首第一句去 AI 化参考](./first-sentence-de-ai.md)。

## 零、自然度 13 项速查（门3#11 + 门4全文复查）

**表面层（① - ⑧，详见本文 §一 ~ §六.五）**

| # | 检查项 | 一句话标准 |
|---|--------|-----------|
| ① | 无平均句 | 同段句长变化率≥30%，禁止5句长度差≤3字 |
| ② | 无解释腔 | 禁止先结论后动作，禁止替角色总结心理 |
| ③ | 无抽象情绪堆叠 | “震惊/愤怒/绝望”必须换为身体/动作/环境 |
| ④ | 无对白同声 | ≥3角色遮名可辨 |
| ⑤ | 有现场感 | 每场景有动作+环境互动 |
| ⑥ | 不过度工整 | 保留≥3处粗粝/未说满/毛边 |
| ⑦ | 情绪有失控 | 高压段有短句/断句/不完整句 |
| ⑧ | 无模板感 | 连续3段首句不重复句式 |

**深层结构（⑨ - ⑫，详见本文 §九）**

| # | 检查项 | 一句话标准 |
|---|--------|-----------|
| ⑨ | 段落思维打破 | ≥30%段无结论句 · 段长标准差≥段均长40% · 有中途转向段 |
| ⑩ | 叙事链非线性 | ≥2处因果断裂/延迟 · ≥1处反应偏移 · ≥1处信息故意遗漏 |
| ⑪ | 词汇去高频化 | 禁用"缓缓/微微/轻轻/淡淡" · 每800字≥1处口语碎片 · 连接词不重复 |
| ⑫ | 信息密度波动 | 密段+空段共存 · ≥1处大事小写 · 解释≤2段连续 · 释放方式≥3种 |

**纹理层（⑬，详见本文 §十）**

| # | 检查项 | 一句话标准 |
|---|--------|-----------|
| ⑬ | 纹理验收 | ≥2处角色毛边 · ≥20%素段 · ≥1配角不推主线的真实个性 · ≥1处信息弯路 · 金句≤4句且间隔≥800字 |

## 一、平均句怎么改

坏处：

- 所有句子长度接近
- 节奏一直匀速
- 读起来平，像模型按稳定概率输出

推荐修法：

1. 一段里至少保留一次明显的长短变化
2. 关键判断前后允许短句打断
3. 不要把每个动作都写成完整说明句

示意：

- 偏 AI：他看着门口，心里忽然生出一种不安的感觉，因为他意识到事情可能已经超出了自己的掌控。
- 更自然：他盯着门口。门没开，但他后背先凉了下来。事情已经不在他手里了。

## 二、解释腔怎么改

坏处：

- 作者把人物心理和关系变化解释完了
- 读者没有自己感知的空间

推荐修法：

1. 先删结论句
2. 再补动作、停顿、视线、错答、回避
3. 让关系变化通过互动体现，不靠总结宣布

示意：

- 偏 AI：她其实已经不再信任他了，只是因为局势紧张，所以她没有把这种情绪表现出来。
- 更自然：她接过他递来的刀，检查了两遍，才慢慢收入鞘里。全过程，她没看他一眼。

## 三、抽象情绪词怎么改

坏处：

- 直接告诉读者“震惊、愤怒、绝望”
- 情绪像标签，不像现场反应

推荐修法：

1. 先找抽象词
2. 问一句“这个情绪在身体上、动作上、环境上怎么显形”
3. 用一个可见细节替掉一个抽象判断

示意：

- 偏 AI：他感到极度愤怒，胸口像是有火焰在燃烧。
- 更自然：他把杯子放回桌上，没放稳，瓷底在木面上磕出一声脆响。

## 四、对白同声怎么改

坏处：

- 每个人都像作者的同一个喉咙
- 台词能随便互换

推荐修法：

1. 给角色加表达偏好：直说 / 绕说 / 冷处理 / 讥讽 / 截断
2. 给角色加回避点：哪些话他不会正面说
3. 给角色加社会位置痕迹：身份、受教育方式、职业、地域、年龄

示意：

- 偏 AI："我认为现在的情况已经非常危险了，我们必须立刻作出决定。"
- 更自然版本 A："再拖一分钟，今晚就得给人收尸。"
- 更自然版本 B："现在不是想的时候。你选，或者我替你选。"

## 五、没有现场感怎么改

坏处：

- 段落像回顾梗概
- 只有气氛和结论，没有可见动作

推荐修法：

1. 把“发生了什么”拆成谁、动作、对象、阻力、结果
2. 让环境参与事件，不只是装饰
3. 让场景里至少有一个会改变局势的小动作

示意：

- 偏 AI：房间里的氛围顿时压抑下来，所有人都意识到事情严重了。
- 更自然：没人接话。墙上的挂钟滴答走了三下，才有人把椅子往后挪开半寸。

## 六、过度工整怎么改

坏处：

- 每段都圆满
- 每句都想漂亮
- 读起来像润得太匀

推荐修法：

1. 保留必要的粗粝感，不把所有边角磨平
2. 留一点没说满的地方
3. 不要每段都收成金句

## 六点五、情绪太干净怎么改

坏处：

- 角色很会表达自己
- 情绪全是标准答案
- 读者知道情绪存在，但摸不到那一下失态和狼狈

推荐修法：

1. 允许短促不完整句，不要每句都写满
2. 允许角色说错、卡住、嘴硬、迁怒、硬撑
3. 让身体反应和动作失手先于“我很痛苦”的结论

示意：

- 偏 AI：他在这一刻感到崩溃，内心的防线彻底瓦解了。
- 更自然：他想说点什么，喉咙却先紧了。半天，才挤出一句不像话的话。

## 七、一轮只改一层

建议顺序：

1. 先改结构性解释腔
2. 再改现场感和动作承载
3. 再改对白区分
4. 再补情绪爆点、狼狈感和不完整句
5. 最后才改句子节奏和局部修辞

如果顺序反了，很容易把文本修得更整齐、更像 AI。

## 八、AI味根源与系统性规避（🚨AI≤5%强制）

上面一到七讲的是"发现问题后怎么改"。但 AI≤5% 的目标要求从**生成时就避免**，而不是事后修补。

### 模型输出的 8 个 AI 味根源

| 根源 | 为什么会这样 | 正文中的表现 | 规避方法 |
|------|------------|------------|---------|
| 概率安全输出 | 模型优先选择高概率、低风险的词 | 用词安全但空泛（"不禁""忽然""似乎"） | 强制使用不常见但精准的动词；禁用高频安全词 |
| 句长均匀化 | 模型倾向输出接近平均长度的句子 | 全段句长相近，读起来像匀速播报 | 每段至少 1 处≤5字短句 + 1 处≥25字长句 |
| 情绪标签化 | 模型直接说"愤怒/悲伤"而非演绎 | "他感到震惊""她内心充满了绝望" | 禁用情绪词直接描写，全部转为身体/动作/环境 |
| 结构对称化 | 模型让段落结构完整对称 | 每段都有起承转合，每段都收得圆满 | 刻意打破：有段只3句，有段8句；有段没结论 |
| 修辞模板化 | 模型反复用相同修辞模式 | "像……一样""仿佛""宛如"高频出现 | 禁用词表强制生效 |
| 叙述解释化 | 模型倾向解释因果 | "因为/所以/于是他明白了"大量出现 | "show don't tell"硬执行 |
| 角色同质化 | 模型让所有角色说理性完整的话 | 遮名后分不清谁是谁 | 强制分配缺陷声线 |
| 开头公式化 | 模型用安全句式开章/开段 | "他意识到""空气中弥漫着" | 章首轮换+段首多样性 |

### 禁用词表（正文生成时强制生效）

以下词汇和句式在正文中禁止作为情绪/氛围的主要描写手段（可在对话中由角色使用，但叙述中禁止）：

**禁用情绪词**：不禁、忽然意识到、内心深处、震惊地发现、一股强烈的、她/他感到、心中涌起、不由自主、瞬间明白了

**禁用氛围句式**：空气中弥漫着……、一种……的感觉笼罩了、这一切注定……、仿佛整个世界都……、时间仿佛静止了

**禁用解释句式**：他知道这意味着……、她明白事情已经……、所有人都意识到了……、因为他清楚……所以他选择了……

**替代原则**：这些词/句式被删除后，用具体动作、物件状态、身体反应、环境变化填充。如果删除后句子空了，说明这个句子本身就只有标签没有内容，需要重写。

## 九、深层结构改写（🚨消除AI统计特征的核心手术）

上面一到八解决的是词句级的AI味。但AI检测工具（GPTZero等）真正测量的是**统计概率分布**：perplexity（困惑度）和 burstiness（突发性）。人类写作天然高困惑度+高突发性，AI天然低困惑度+低突发性。要从76%AI降到≤5%，必须改写作的**思维结构**。

### 9.1 段落结构改写

**病因**：AI 的每个段落都是完整的思维单元——有主题、有展开、有收束。人不这么写。

| 改写操作 | 示例 |
|---------|------|
| **砍掉段尾总结句** | ❌ "……他终于明白，这一切都是局。" → ✔ 直接删掉这句，段落停在上一个动作上 |
| **制造1句段** | 在关键转折/停顿处，单独拎出一个短句成段。"门开了。" 独占一段 |
| **段落中途打断** | 段落写到一半，插入一个声音/动作/意外，段落主题被迫偏移 |
| **合并短段为长段** | 把3个短段合成1个长段，让一个场面有沉浸式的连续体验 |
| **拆长段为碎段** | 把一个说理段拆成2-3个碎段，中间插入动作/沉默/环境 |

### 9.2 叙事链改写

**病因**：AI 叙事是线性因果链。事件→反应→判断→行动。人类叙事会岔开、绕回、跳过。

| 改写操作 | 示例 |
|---------|------|
| **因果延迟** | 事件发生后，不马上写反应——先写一个不相干的细节（墙上的钟、窗外的鸟、桌上没喝完的茶），再绕回来 |
| **反应偏移** | 该哭的时候写笑、该怒的时候写沉默、该紧张的时候写了一个完全无关的动作——人在极端情绪下经常"反应不对" |
| **先果后因** | 先写"她手上多了一道口子"，过3句再交代是什么时候划的 |
| **信息遗漏** | 故意不交代某个细节，让读者在后文自己拼。"他回来的时候换了件衣服。"——不解释为什么换 |
| **视角污染** | 环境描写带上POV角色的偏见。不写"房间很旧"，写"这破地方连个能坐的地方都没有"——带上角色的烦躁 |

### 9.3 词汇概率改写

**病因**：AI 每个位置都选概率最高的词。人类会选"差不多对但不是最常见"的词。

| 改写操作 | 示例 |
|---------|------|
| **动词替换** | "走向"→"蹭过去/挪过去/溜过去/横着过去"；"看着"→"盯/瞟/扫/眼神钉在/目光黏在" |
| **删除安全修饰词** | "缓缓站起来"→"站起来"或"膝盖先响了一下，人才站起来"——要么删，要么换成有信息量的 |
| **注入口语碎片** | 在叙述（不仅对话）中插入："得了""压根""那玩意儿""鬼知道""横竖" |
| **连接词替换** | "然后他走到门口"→直接写"门口。他的手搭上了门把。"——用场景切换代替连接词 |
| **比喻本土化** | "像一头受伤的野兽"→用本书世界观内部的东西做比喻——如果是玄幻世界，比喻用这个世界里的生物和现象 |

### 9.4 信息密度改写

**病因**：AI 均匀分配信息。人类作者会在某处突然密集、在某处刻意留白。

| 改写操作 | 示例 |
|---------|------|
| **制造信息空段** | 在两个信息密段之间，插入一个只有感官/动作/沉默的段落——0信息，纯氛围 |
| **大事小写** | 重大事件用一句话带过："三天后，他死了。"——然后花5句写旁边人怎么放下筷子 |
| **解释打断** | 连续解释超过2段时，强制插入一个动作/声音/意外打断 |
| **释放方式轮换** | 这条信息通过对话带出，下条通过角色发现一个物件带出，再下条通过他人的异常反应间接暴露 |

### 改写优先级

深层改写的执行优先级（影响AI检测最大→最小）：

1. **段落结构**（段段有结论是AI最大指纹）
2. **词汇概率**（安全词堆积直接拉低perplexity）
3. **叙事链**（线性因果是AI第二大指纹）
4. **信息密度**（均匀分配是全文级统计特征）

**一轮只改一层**原则仍然适用——先改段落结构（最见效），再改词汇，再改叙事链，再改信息密度，最后改纹理。

## 十、纹理级改写（🚨最有效的不是改词，而是改纹理）

上面一到九解决的是"不让检测工具判为AI"。但真正让人类读者一眼识破AI的，不是用了哪个词，而是**文本太干净、太高效、太完美**。人类写作天然带有冗余、笨拙、试错和不完美。这些不是缺陷，是"人味"的核心载体。

### 10.1 角色毛边改写

**病因**：AI让角色反应总是精准高效——发现真相→震惊→接受→行动，一步到位。真人不这样。

| 改写操作 | 示例 |
|---------|------|
| **让角色卡壳** | 父亲恢复记忆时，不马上连续说出多个高价值细节。先卡住："那个……那个地方……不是，不对，是另一个。"说错了，被纠正，再慢慢想起来 |
| **让角色否认** | 角色得知真相时，第一反应不是震惊接受，而是否认："不可能。你搞错了。"——需要第二次证据才松口 |
| **让角色说废话** | 紧张时不是都在说有用的话，有人会说无关的废话掩饰紧张："这茶凉了没有？谁泡的？"——明明在讨论生死大事 |
| **让反应不漂亮** | 英雄救人后不是帅气转身，而是蹲在地上喘气，手抖得拧不开水瓶盖 |
| **让理解慢半拍** | 别人解释了一遍，角色没完全听懂，问了一个很笨的问题，被白了一眼，才恍然大悟 |

### 10.2 修辞密度改写

**病因**：AI每段都在"写"——比喻、拟声、意象、感官，段段都有修辞手法。真人写作有的段就是在记录。

| 改写操作 | 示例 |
|---------|------|
| **制造素段** | 有的段只写动作："他站起来，把椅子推回去，拿了外套出门。"——零修辞，纯记录 |
| **只写对话段** | 整段只有对话，不加任何动作描写、表情描写、心理描写。两个人一来一回，干巴巴地说事 |
| **只写物件段** | "桌上有三个杯子。最左边那个没洗。中间的倒扣着。右边的里面还有半杯水，水面上浮着一片茶叶。"——纯物件记录 |
| **留白段** | 一段只有一个动作或一个声音，没有解释、没有感受、没有修辞。"门关上了。" |

**标准**：全章至少 20% 的段落是素段。如果每段都在用修辞，整体就像润色过的命题作文。

### 10.3 配角真实个性改写

**病因**：AI的配角只在推进主线时出场，说的每句话都是功能性信息。真人小说里配角有自己的"废话"和个性。

| 改写操作 | 示例 |
|---------|------|
| **加口头禅** | 老周每次开口都先"这个嘛"，邻居阿姨总说"你们年轻人不懂" |
| **加职业惯性** | 警员不自觉地用审讯口气问路人问题，医生看到别人受伤先问"最后一次破伤风是什么时候" |
| **加偏见** | 邻居大爷默认外来人不靠谱，小卖部老板觉得穿西装的都是骗子 |
| **加多嘴** | 出租车司机主动讲一段和主线完全无关的八卦，快递员送东西时嘴里嘟囔着别家的投诉 |
| **加习惯动作** | 某角色说话时总摸后脑勺，另一个总把手插口袋，第三个总低头看手机——不需要解释为什么 |

**标准**：这些个性细节**不直接推进主线**，但它们让文本像有很多真实的人存在，而不是只有为剧情服务的工具人。

### 10.4 信息弯路改写

**病因**：AI让信息揭示太顺——发现线索→正确理解→推进下一步。被最优路径推着走。真人会走弯路。

| 改写操作 | 示例 |
|---------|------|
| **理解错一半** | 主角第一次看到新规则的线索，理解错了一半意思，按错误理解行动了一段，才被纠正 |
| **信息不完整** | 父亲留下的残页缺了关键几行，主角只拿到了半截信息，得靠试错补全 |
| **试错** | 主角用了一种方法没奏效，换了另一种还是差一点，第三次才找对方向——不是一步到位 |
| **走弯路再修正** | 主角以为线索指向A地点，去了才发现是错的，得折返重新推理——浪费了时间但增加了真实感 |
| **被误导** | 有人（不一定是反派）给了错误信息，主角信了，走了一段歧路才发觉不对 |

### 10.5 金句节制改写

**病因**：AI每章都在制造"可截图可传播的精句"，高密度金句轰炸。越想让人记住，越容易显得被设计过。

| 改写操作 | 示例 |
|---------|------|
| **削减金句密度** | 一章 4300 字，有 2-3 句金句就够了。超过 4 句 → 削掉最弱的 |
| **拉开金句间距** | 两句金句之间至少间隔 800 字的"老实叙事"段落 |
| **禁止连续高光** | 不允许连续 2 段都有设计感明显的句子——中间必须夹叙事素段 |
| **保留核心削减装饰** | 一章真正值得留的金句就那 1-2 句，其他的"不错但没必要"的修辞就让它平着过 |
| **让金句从处境长出来** | 金句不是作者设计好塞进去的，而是角色在压力下被逼出来的。如果删掉前面的处境铺垫，这句话就没有力量 → 说明它是自然的 |

### 纹理改写优先级

纹理层的 5 条规则执行优先级（对降AI效果最大→最小）：

1. **角色毛边**（W1）→ 最直接打破AI的"精准高效"模式
2. **修辞密度**（W2）→ 最直接降低"段段都在写"的AI感
3. **信息弯路**（W4）→ 打破"最优路径"让故事像真人在摸索
4. **配角真实个性**（W3）→ 增加"无用但真实"的噪声，降低模板感
5. **金句节制**（W5）→ 控制"设计感"密度，让文本不像被润色过
