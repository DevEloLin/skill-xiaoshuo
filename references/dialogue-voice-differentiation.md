# 对白分声线参考

目标：

解决一个常见问题：所有人都会说话，但都说得太像“理性、克制、完整的作者”。

真正像人的对白，不是都聪明、都稳定、都表达准确，而是各有毛病。

## 一、同声腔的典型表现

- 所有人都用完整句
- 所有人都讲重点，不绕，不岔，不遮掩
- 所有人都情绪稳定，哪怕快炸了还在有条理地表达
- 台词能随便换角色，意思差不多都成立

## 二、怎么把人说开

### 1. 有人爆

特点：

- 句子短
- 说重话
- 会打断
- 情绪先到，逻辑后补

示意：

- 稳版："我认为你现在的决定有问题。"
- 爆版："你再说一遍。再说一遍试试。"

### 2. 有人碎嘴

特点：

- 话多
- 会绕
- 会补很多没必要的小句子
- 常常在废话里把真情绪漏出来

示意：

- 稳版："我不想去。"
- 碎嘴版："我去？我去干什么，我去了也没用，你又不是不知道我最烦那种地方。"

### 3. 有人冷笑

特点：

- 字不多
- 不抬嗓
- 句子轻，但伤人
- 喜欢用反问、轻描淡写、顺手一刀

示意：

- 稳版："你这样说并不公平。"
- 冷笑版："现在才想起讲公平？晚了吧。"

### 4. 有人说废话

特点：

- 不是真的没内容
- 是在躲重点、掩心虚、拖时间、维持表面
- 废话里反而最像真人

示意：

- 稳版："我其实害怕。"
- 废话版："这地方也太闷了。你们这灯是不是坏了，照得人头疼。"

## 三、让对白像人，而不是像作者

不要只给角色“说话风格”四个字，要给他：

1. 他一急就会出现什么毛病
2. 他会在哪种问题上绕开不说
3. 他会用什么方式伤人或自保
4. 他会不会把重点藏在废话里

## 四、对白修订顺序

1. 先找出所有过于完整、过于理性的句子
2. 再判断这句到底该归谁说
3. 再把它改成符合这个人缺点的说法
4. 保留一点不好看，但更像人的边角

## 五、自检问题

1. 这段对白是不是所有人都太会说了
2. 有没有人一着急还在讲标准答案
3. 有没有人该爆却没爆
4. 有没有人该碎却碎得不够
5. 有没有人该冷，却说得太正经
