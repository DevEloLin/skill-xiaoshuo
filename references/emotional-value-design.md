# 情绪价值设计参考

目标：

让作品不只是“写得对”，而是能给读者明显的情绪回报和共感。

## 一、什么叫高情绪价值

不是简单地堆情绪词，也不是每章都痛哭或高喊。

高情绪价值通常来自：

- 压抑后的兑现
- 委屈后的反弹
- 想要却不敢说的东西被逼出来
- 角色处境具体到读者能代入
- 一个很小但很真切的细节，把大情绪钉住

## 二、共感不是解释出来的

读者会共感，不是因为作者说“他很痛苦”，而是因为读者看见：

- 他具体失去了什么
- 他为什么偏偏在意这个
- 他还要装没事
- 这一刀落在了哪里

## 三、常见高情绪价值类型

- 爽点：压了很久，终于翻回来
- 刀点：好不容易抓住，又失去
- 委屈点：角色明明没错，却必须吞下去
- 拉扯点：想靠近，但就是不能靠近
- 爆点：忍了太久，终于炸开

## 四、设计原则

1. 情绪必须和具体处境绑定
2. 先有压抑，再有兑现
3. 情绪兑现后，关系或局势要变
4. 不要整章都高，留出爬升空间

## 五、自检问题

1. 这一章最值钱的情绪点在哪里
2. 读者为什么会共感，而不是只看热闹
3. 这一刀 / 这一爽有没有具体代价和后果
