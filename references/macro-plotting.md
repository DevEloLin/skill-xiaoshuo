# 大布局参考

## 目标

让故事形成“大棋盘”效果，但不靠空泛地把世界写大，而是让人物命运、势力对局、世界变化三层结构彼此牵动。

## 何为大布局

真正的大布局通常至少包含：

1. 一条明确主线
2. 两条以上可回流主线的支线
3. 一条在前期隐身、后期改写理解的暗线
4. 两个以上拥有不同利益目标的势力或棋手
5. 近中远三层伏笔
6. 三个以上能独立影响局面的核心群像角色

## 常见误区

### 误区 1：只有世界观很大

世界设定很多，不等于布局大。布局大，必须让设定真正参与到人物选择和事件后果中。

### 误区 2：支线很多，但互不相关

支线不是附件。有效支线应该满足至少一项：

- 推动主线
- 改变主角选择
- 暴露世界真相
- 放大终局冲突

同理，有效群像角色也应满足至少一项，而不是只负责围观、赞叹或解释。

### 误区 3：伏笔只有一个点

真正有效的伏笔往往不是单点提示，而是：

- 第一次出现时像背景
- 第二次出现时像巧合
- 第三次才让读者意识到它一直都在那里

## 推荐结构

### 主线

主线负责回答：这部小说最终在讲什么。

### 支线

支线负责回答：主线为什么复杂，代价为什么成立，人物为什么立得住。

### 暗线

暗线负责回答：读者此前的理解哪里是错的，或者哪里还不完整。

## 草蛇灰线的基本用法

### 第一层

把伏笔埋成日常细节、背景物、随口提及、次要角色一句话。

### 第二层

在不同情境下轻轻碰到同一个元素，但不立刻解释。

### 第三层

在回收时不仅解释当前问题，还能反照前文，让读者回头看见一条隐藏已久的线。

## 自检问题

在设计总纲或中后期大剧情时，自查：

1. 主线之外是否还有真正有用的两条以上支线
2. 暗线是不是只靠藏信息，而不是靠重组旧信息
3. 伏笔是否存在近回收、中回收、远回收三个层次
4. 大势力是不是各自有行动和代价，而不是只会围着主角转
5. 单章推进是否能回头影响更大的棋局
6. 是否至少有 3 个核心角色能在不同位置独立推动局势

## 总阴谋套子阴谋：什么时候需要另一张图

结构网图回答“主线、支线、暗线怎么交汇”，伏笔矩阵回答“线索何时埋、何时回收”，但二者都不完整回答“谁在做局、为何能做成、谁能拆局”。

当作品需要多个棋手互相利用、一个大目标通过数个独立小局推进、或揭示必须反照旧事件时，额外建立 `conspiracy-weave.md`。它用 L0 终局局、L1 战略局、L2 执行局、L3 线索载体和五类因果边（资助/利用/掩护/误导/反制）管理局网。

关键原则：

1. 小局能独立成立，不知道大局的执行者仍有自己的动机和收益。
2. 至少保留一条独立利益线或反制线；不是所有巧合都属于同一幕后人。
3. 每次重要揭示重释至少两项旧证据，并逼出一次付代价的新选择。
4. 棋手有信息、资源和时间限制；布局可以失败、偏移和反噬。

字段与过门规则以 [多层阴谋与布局编织协议](./conspiracy-weaving-protocol.md) 为准。
