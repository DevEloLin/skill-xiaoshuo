# 小说质量标准

## 结构质量

- 目标明确：读者能看出本章或本段在推进什么
- 冲突有效：不是空喊紧张，而是真有选择压力
- 结果成立：事件结束后，局面发生了可感知变化
- 多线有效：主线、支线、暗线至少两层以上互相牵动，而不是平行摆放
- 布局成立：章节推进不只是眼前冲突，还能回头影响更大的局势
- 节奏有效：章节前段尽快给压力，中段能升级，后段能把问题推向下一轮
- 字数成立：默认单章达到最低字数，并且不是靠重复解释、空转对话或设定复述凑出来
- 解释不过载：连续大段只有解释、没有动作承接、没有新后果时应触发重写或拆段；经验阈值可先按连续 600 到 800 字纯解释段处理

## 情绪价值质量

- 情绪兑现存在：不是只有事件推进，还能给读者明显的爽、疼、委屈、拉扯或反弹
- 共感具体：读者能看见角色具体在失去什么、忍什么、想要什么，不只是抽象痛苦
- 情绪有回报：压抑之后有兑现，兑现之后有后果，不是白煽情
- 金句适量：有能留下来的句子，但不是句句都在发光，也不是脱离人物的作者发言

## 世界观质量

- 规则成立：世界规律不是装饰，能真实约束人物和势力行为
- 宇宙成立：宇宙层设定能解释世界边界、上限和代价
- 地图成立：地理和宇宙版图能解释资源、战争、迁徙、贸易和探索顺序
- 层级对应：宇宙层、世界层、地区层在同一套逻辑下互相对应
- 设定可推演：规则不是临时补丁，而是能推导出后果和限制

## 人物质量

- 角色有区分度：说话、行动、价值取向不混同
- 行动有因果：人物做事不是为了配合剧情硬拐
- 情绪有触发：情绪变化前有明确刺激
- 群像不失衡：主角团外至少有反派、敌对方、中立方或普通人层面的角色真正推动局势
- 角色有钉子：至少有一个一眼可记的标签、场面或毛病能把角色钉住
- 魅力有代价：不是只帅、只强、只狠，而是有裂口、有反差、有会失手的地方
- 队伍有活气：主角团里最好有人能打破过正、过闷、过整齐的气氛
- 反派有层次：反派队伍里不应全员冷硬高配，允许有人搞笑、翻车、误判、出丑，但必须服务剧情

## 语言质量

- 少用空泛评价词，如”震惊””愤怒””绝望”直接堆叠
- 多用动作、物件、环境、细节承载情绪
- **🚨形容词堆砌零容忍**（升级版，详见 [anti-ai-thresholds.md §六](./anti-ai-thresholds.md#六形容词堆砌零容忍专项)）：同名词修饰 ≤2 · 千字形容词 ≤30 · 类比修辞 ≤3/千字 · 程度副词 ≤2/千字 · 禁 `XX的XX的` 链 · 禁段首形容词起首；删后用动词 / 物件 / 身体反应 / 环境互动替代
- **细节代替概括**：不写”他很紧张”，写手指在桌沿划出白印；不写”战场很惨”，写地上那只还攥着刀柄的断手
- **调动多感官**：关键场面不能只有视觉，至少补入一种非视觉感官（听觉/嗅觉/味觉/痛觉/触觉/温度），且感官必须贴合人物处境
- **侧面描写优先**：展示力量、情绪、危险时，优先通过旁观者反应、环境变化、物件状态间接呈现，不靠正面硬写+形容词
- **感官细节承载情绪**：汗、耳鸣、铁锈味、指尖麻木——这些不是装饰，是情绪的载体，必须和人物当下状态绑定
- **象征细节承载主题**：反复出现的物件、声音、气味用于暗示主题和伏笔；装饰性细节如果既不承载情绪也不承载主题，删掉
- 避免连续重复相同句式和相同修辞
- 对话避免过度解释背景资料
- 平台投稿稿件要避免平均句、总结腔、说明腔和一眼可辨的模板化修辞
- 角色对白应有可区分的口吻，不能互换后仍成立
- 情绪爆点段落允许保留短句、断句、不完整句和狼狈感，不能全都修成标准腔
- 不同角色的对白应存在明显缺点差异，至少允许有人爆、有人碎嘴、有人冷笑、有人用废话遮掩
- 分镜感应通过焦点切换、动作接力、物件特写、声响推进和后果先行自然出现，不靠解释”镜头”

## 去 AI 化质量（🚨硬性目标：AI检测≤5%，Human ≥95%）

> **量化计算口径以 [anti-ai-thresholds.md](./anti-ai-thresholds.md) 为 SSOT**。本节表格仅作速查；遇到阈值含糊（如"句长变化率"具体怎么算）时，以 SSOT 为准。

**13 项反AI硬检（门3#11 + 门4P0#8，FAIL即BLOCK）**：

**表面层**：

| # | 检查项 | 标准 |
|---|--------|------|
| ① | 无平均句 | 同段句长变化率≥30%，禁止连续5句长度差≤3字 |
| ② | 无解释腔 | 禁止先结论后动作，禁止替角色总结心理 |
| ③ | 无抽象情绪堆叠 | “震惊/愤怒/绝望”等必须换为身体反应/动作/环境变化 |
| ④ | 无对白同声 | ≥3角色遮名可辨，任意两角色对话不可互换 |
| ⑤ | 有现场感 | 每场景有改变局势的动作+环境参与 |
| ⑥ | 不过度工整 | 保留≥3处粗粝/未说满/毛边，禁止每段都圆满收束 |
| ⑦ | 情绪有失控 | 高压段有短句/断句/不完整句/嘴硬/失手 |
| ⑧ | 无模板感 | 连续3段首句不重复句式，全章至少4种段首句式 |

**深层结构**：

| # | 检查项 | 标准 |
|---|--------|------|
| ⑨ | 段落思维打破 | ≥30%段无结论句，段长标准差≥40%，有中途转向段 |
| ⑩ | 叙事链非线性 | ≥2处因果断裂，≥1处反应偏移，≥1处信息遗漏 |
| ⑪ | 词汇去高频 | 无缓缓/微微/轻轻，每800字≥1口语碎片 |
| ⑫ | 信息密度波动 | 密段空段共存，≥1处大事小写，解释≤2段连续 |

**纹理层**：

| # | 检查项 | 标准 |
|---|--------|------|
| ⑬ | 纹理验收 | ≥2处角色毛边（卡壳/说错/否认/废话）· ≥20%素段（零修辞）· ≥1配角有不推进主线的真实个性 · ≥1处信息弯路 · 金句≤4句且间隔≥800字 |

**禁用词表（叙述中禁止，对话中角色可用）**：
不禁、忽然意识到、内心深处、震惊地发现、一股强烈的、心中涌起、不由自主、瞬间明白了、空气中弥漫着、仿佛整个世界都、时间仿佛静止了

**补充标准**：
- 开头 300 字内有抓手，不像设定说明或作文开场
- 每章第一句尽量先给现场、异样、动作、物证或后果，而不是先给抽象感觉和总结判断
- 最近几章第一句在手法和气质上有轮换，不会连续都写成同一种冷硬抓手、同一种景物腔或同一种作者腔
- 连续几章的章首类型有轮换，不是反复从主角到场、主角判断或团队对话起手
- 抽象情绪词不过度堆叠，情绪更多由动作和场景承载
- 关键段落不是”把意思解释完整”，而是保留读者参与空间
- 段落节奏有松紧变化，不是整段同频平铺
- 删掉人名后，对白仍有一定辨识度
- 情绪上冲时，文本允许出现失语、卡顿、嘴硬、失手，而不是始终维持专业平稳的表达
- 如果连续 600 到 800 字主要都在说明规则、总结关系或解释心理，而缺少动作承接、场面变化或新后果，应判为解释过载

### 🚨 形容词堆砌零容忍（[§六 速查](./anti-ai-thresholds.md#六形容词堆砌零容忍专项)，FAIL 即 BLOCK）

| # | 规则 | 阈值 |
|---|------|------|
| 7.1.1 | 同名词修饰 | ≤ 2 个 |
| 7.1.2 | 千字形容词总量 | ≤ 30 |
| 7.1.3 | 类比修辞密度（像/如/宛如/仿佛） | ≤ 3 处/千字 |
| 7.1.4 | 程度副词密度（非常/极其/十分） | ≤ 2 处/千字 |
| 7.1.5 | "XX的"链长 | ≤ 1（禁 `XX的XX的`）|
| 7.1.6 | 同段重复修饰 | 同一形容词不修饰同段两个名词 |
| 7.1.7 | 形容词起首段 | 段首禁形容词/副词 |

替换原则：删完用 → 精准动词 / 具体物件 / 身体反应 / 环境互动 / 直接动作。

### 🚨 AI 感残留扫描（[§七 速查](./anti-ai-thresholds.md#七ai-感残留全维扫描门-4-完稿后)，命中触发自动修复）

- **句法层**：主语开头段 ≤60% · "他/她"开头句 ≤35% · 时间状语起首段 ≤2/章 · 排比句 ≤1/章（≥1 即 FAIL）· 完整句比例 ≤75%
- **词汇层**：XX地 ≤5/千字 · 了字结尾 ≤70% · 抽象名词（思绪/情绪/感觉/氛围）≤3/千字 · 量词单调（≥4 次"一个/一种/一片/一阵"即 FAIL）
- **段落层**：段尾收束 ≤30% · 段首景物 ≤15% · 过渡词开头段 ≤2/章
- **修辞层**：三层比喻嵌套（"像 X 的 Y，仿佛 Z"）禁用 · "如同+名词+一般" ≤1/章 · 拟人化场景 ≤3/章
- **全局**：的地得密度 ≤80/千字 · 章末金句收尾连续 ≤1 章

## 连载质量

- 每章有追更点
- 每个阶段有阶段性兑现
- 伏笔和悬念能被管理，而不是无限累积
- 伏笔有层级：至少有近回收、中回收、远回收三层设计
- 棋盘有变化：势力、关系或认知层面持续发生重新洗牌
- 世界有反馈：章节推进会反作用于地图、秩序、势力分布或世界认知
- 非主角推进存在：不是所有事件都等主角团出手才启动
- 冲突密度稳定：不能长时间只说明、赶路、回顾而没有新压力
- 章节厚度足够：不是只写完了结果，还写出了过程、阻力、反应和余波

## 常见问题

- 世界观介绍过量，压垮开篇节奏
- 配角只承担说明功能，没有自身诉求
- 章节很顺，但没有给读者足够强的情绪回报
- 反转缺乏铺垫，只靠信息遮蔽
- 正文语言看似流畅，但没有具体画面
- 正文有画面，但几乎只有视觉，缺少身体层和现场层
- 形容词堆砌严重，一句话里三四个形容词修饰同一个名词，像在凑字数
- 全篇概括性判断过多（"他很愤怒""气氛紧张""场面混乱"），缺少可感知的细节支撑
- 只有正面硬写，从不通过旁观者、环境、物件间接呈现，像作者在替读者下结论
- 细节堆了不少但全是装饰，既不承载情绪也不呼应主题，删掉不影响任何东西
- 文本过于工整，像 AI 按标准答案修出来
- 角色反应全是精准高效的最优路径，没有卡壳、说错、否认、废话——太聪明了不像真人
- 每段都在用修辞手法，没有纯动作/纯对话/纯物件的"素段"——像命题作文
- 配角只在推进主线时出场，说的每句话都是功能信息，没有真人的口头禅和偏见
- 信息揭示太顺畅，角色永远一次看懂线索、一次理解规则——太像被最优路径推着走
- 金句密度太高，每段都像在制造可截图的句子——越想让人记住越容易显得被设计过
- 段落把意思解释太满，没有隐形分镜推进和读者自行感知空间
- 情绪最重的段落依然干净顺滑，像“知道该难受，但不会失态”
- 连续多章用同一种章首模板，看起来像自动生成
- 连续多章第一句都像“他意识到”“她有种感觉”“空气里弥漫着”这类安全开场
- 连续多章第一句虽然字面不同，但手感完全一样，像同一个模板在换词
- 单章字数长期低于最低要求，像半章稿或未完成稿
- 为了补字数反复解释同一件事，出现明显灌水
- 想写金句，但写成了脱离人物口吻的社媒文案
- 主角团全员太正经，像开会班子，没有一个会犯贱、会拆台、会搅活气氛的人
- 反派队伍全员都太懂、太狠、太稳，没有搞笑和翻车层次
- 角色说话方式高度统一，像同一个人换名字
- 所有人都过于理性、克制、会表达，像同一个作者在分配台词
- 角色设定不少，但没有一个真正能钉在读者脑子里的标签
- 解释过满，读者几乎没有自行感知空间
- 风格忽然切换，像不同作者在接力
- 反派和敌对阵营只有挨打时存在，平时没有动作线
- 支线很多，但全都不能反哺主线
- 伏笔只有一次提示，回收时像强行解释
- 棋盘写得很大，但没有真实行动承载
- 宇宙设定很宏大，但对剧情没有约束力
- 地图很详细，但不影响路线、资源和冲突
- 规则前后不一，需要时出现，不需要时消失

## 修订优先级

建议按以下顺序修：

1. 结构问题
2. 人物逻辑
3. 信息顺序
4. 场景具体性
5. 语言润色
