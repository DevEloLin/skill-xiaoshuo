# 模板索引（60 个 assets 模板的"用哪个 / 何时用 / 跟哪个重叠"）

> 这份索引解决三个问题：
> 1. **要写新章节，应该建哪个状态文件**
> 2. **角色 / 群像 / 章节 这类有多份模板的，到底用哪个**
> 3. **哪些模板是必建，哪些只是"按需"**

`assets/` 下共 60 个模板（含 1 份不带 `-template` 后缀的 `continuity-checklist.md`）。本索引按阶段分类、标注必备级别、列出重叠关系。

## 二、重叠决策树（同名/同主题模板用哪个）

### 角色类（6 选 1 或多选）

```
要建一个角色 →
├── 只是普通配角，需要基本信息
│   → character-template
├── 是主角或核心配角，要驱动剧情
│   → character-engine-template（动机+伤口+目标）+ character-template
├── 主角，且要让读者记得住
│   → magnetic-character-template（标签+魅力+代价）
├── 角色有复杂前史
│   → character-biography-template
├── 是搞笑担当 / 戏剧角色
│   → funny-role-template 或 quotable-line-and-comic-role-template
└── 是 ≥3 角色的群像项目
    → ensemble-cast-template + ensemble-arc-matrix-template
       （单个角色仍按上述选 1 - 2 个分项模板）
```

**对应关系**：
- character = 基础卡（每个角色都有）
- character-engine = 推进力学（主角 + 关键配角加这个）
- character-biography = 历史（重要角色加这个）
- magnetic-character = 魅力强化（主角加这个）
- funny-role / quotable-line = 戏剧担当特化（群像里 1-2 个加）

### 群像类（3 选）

```
群像项目 →
├── 群像总管理
│   → ensemble-cast-template（每个角色一行）
├── 每个角色独立弧光
│   → ensemble-arc-matrix-template（行=角色，列=阶段）
└── 多势力对抗推动
    → multi-faction-dynamics-template + faction-board-template
       （前者管"动作线"，后者管"棋盘格局"）
```

### 章节类（6 选）

```
章节相关 →
├── 准备写下一章
│   → chapter-card-template（单章目标）
├── 章节之间承接出问题
│   → chapter-alignment-template（前后章对齐）
├── 章节写完
│   → chapter-summary-template（写入 07-memory）
├── 最近 10 章互相失联
│   → ten-chapter-echo-template（呼应板）
├── 字数控制不住
│   → chapter-length-control-template
└── 章首老是同一种起手
    → chapter-opening-rotation-template + first-sentence-template
```

### 大纲类（3 选）

```
大纲层 →
├── 全书架构
│   → outline-template
├── 单卷
│   → volume-outline-template（每卷 1 份）
└── 章节级推进
    → detailed-outline-template
```

### Canon / 状态类（4 主要）

```
状态类 →
├── 不可改的设定（人名、能力上限、关键事实）
│   → canon-facts-template
├── 事件时间顺序
│   → timeline-template
├── 状态文件总索引
│   → memory-index-template
└── 潜在冲突点台账（"这两个设定可能矛盾"）
    → consistency-ledger-template
```

## 三、必备 vs 可选（按项目类型）

### 短篇（≤ 3 章）

最低 5 个：`project-brief` · `worldbuilding` · `character` · `outline` · `chapter-card`。
其余按内容补。

### 长篇连载（11 - 30 章单卷）

10 个最低骨架（其中 7 个是 A 级状态文件）：

```
立项: project-brief
设定: worldbuilding · character (每个角色)
大纲: outline · chapter-card (每章)
场景: scene-engine
状态: canon-facts · timeline · memory-index · chapter-summary
质检: quality-gate
```

### 多卷长篇（>30 章）

在长篇基础上加：

```
plot-architecture · foreshadow-matrix · volume-outline · detailed-outline
chapter-alignment · ten-chapter-echo · consistency-ledger · series-state
```

### 群像项目

在以上基础上加：

```
ensemble-cast · ensemble-arc-matrix · multi-faction-dynamics
faction-board · dialogue-voice-matrix · relationship-map
```

### 宏大世界观

在以上基础上加：

```
cosmology · world-rules · world-map · universe-map
```

### 双轨剧本（O 模式）

在场景骨架基础上加：

```
screenplay-output（与 scene-engine 共用 scene_id）
```

### 投稿润色（M 模式）/ 去 AI（N 模式）

```
de-ai-diagnostic · submission-polish · rewrite-prompt
（其它项目模板按已有继续用）
```

### 日更（Q 模式）

```
daily-continuation（独立模板，触发即用）
```

## 五、检索规则

1. 写新章节前：先确认有没有 `chapter-card-template` 填好；没有 → 创建
2. 找不到该用哪个模板时：先看本索引 §二（决策树），不存在的组合查 §一（按阶段）
3. 同名重叠模板：优先看 §二 的"对应关系"
4. 项目刚启动：按 §三 选必备包，避免一次性建 60 个文件
5. 模板设计原理 / 何谓"标签 + 魅力 + 代价"：查 §四 references 列表

## 六、维护规则

- 新增 assets 模板时，本文件同步加行
- 删除 / 合并 assets 模板时，本文件需先标 deprecated 再清理
- 模板与 references 的对应表（§四）变化时同步更新
