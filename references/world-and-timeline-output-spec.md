# 世界地图 / 宇宙地图 / 时间线 输出约定（逻辑闭环 SSOT）

> **目标**：让"世界观 → 世界地图 → 宇宙地图 → 时间线"形成可强制的输出闭环，而不是只建世界观就完事。
> 凡是仓内涉及"输出世界地图 / 输出时间线"的规则、模板、template-index 条目，**都以本文件为口径**。

---

## 零、闭环原则

世界观、世界地图、宇宙地图、时间线四者**不是平行的可选项**，而是**有依赖关系的闭环**：

```
世界观（worldbuilding）
   ↓ 必须解释
世界规则（world-rules）
   ↓ 必须落地为
世界地图（world-map） ← 必有 ↔ 时间线（timeline）必有
   ↓ 宏大叙事追加
宇宙地图（universe-map） ← 含 ↔ 时间线宇宙级事件
   ↓ 全部反哺
Canon 事实表（canon-facts）→ 章节卡 → 正文
```

**硬规则**：

1. 任何世界观若**有空间感**（多地点 / 多势力 / 跨区域行动），**必须**建 `world-map`；漏建 → 门 1 BLOCK
2. 任何项目（无论短篇 / 长篇）**必须**建 `timeline`；漏建 → 门 1 BLOCK
3. 任何宏大叙事（多界 / 多位面 / 跨星域）**必须**建 `universe-map`；漏建 → 门 1 BLOCK
4. 章节卡里出现的地点 / 时间，**必须**在 world-map / timeline 中存在；不一致 → Canon 冲突 → 门 4 BLOCK
5. 时间线事件 ≥ 1 必须**带地点**字段；地点必须在 world-map 中存在 → 形成"事件 ⇄ 地点"绑定

## 一、世界地图输出约定（world-map）

### 1.1 触发条件

| 项目类型 | world-map 必备级别 |
|---------|------------------|
| 短篇 / 单地点故事（< 3 章 + 全程 1 个场景） | ⚪ 可选 |
| 短篇 / 多地点故事 | 🟡 推荐 |
| 长篇连载（11 - 30 章） | 🔴 必建 |
| 多卷长篇 | 🔴 必建（每卷可有局部细化版） |
| 玄幻 / 修仙 | 🔴 必建（含力量分布） |
| 权谋 / 多势力 | 🔴 必建（含势力辖区） |
| 战争 / 军事 / 谍战 | 🔴 必建（含战略要冲） |
| 悬疑 / 探案 | 🔴 必建（含案发地理） |
| 古装 | 🔴 必建（含朝代地理） |
| 都市 / 言情 | 🟡 推荐（活动半径 + 关键地点） |
| 克苏鲁 / 末日 | 🔴 必建（禁区 + 禁忌带）|
| 脑洞 / 末世 | 🔴 必建（适应区 + 异变区）|

### 1.2 必填字段（最低）

| 字段类 | 字段 | 最低要求 |
|--------|------|---------|
| **总览** | 世界名称、地理类型、世界边界、关键生态区 | 全部填，类型从枚举选 |
| **核心区域** | 至少 3 个区域，每区含：名称 / 地理位置 / 资源特征 / 主要势力 / 进入难度 / 叙事功能 | 题材为权谋/玄幻/战争时 ≥ 5 区域 |
| **流动路径** | 贸易 / 战争 / 朝圣 / 迁徙 / 禁区 | 至少填 2 类，禁区必填 |
| **地图与剧情对应** | 埋伏笔地点 / 天然冲突地 / 推进顺序锚点 / 改棋盘地点 | 至少 4 个地点带剧情功能 |

### 1.3 题材特化字段

| 题材 | 必加字段 |
|------|---------|
| 玄幻 / 修仙 | 灵气分布 / 福地 / 凶地 / 宗门辖区 / 秘境入口 |
| 权谋 / 古装 | 势力辖区 / 朝廷直辖 / 边境 / 缓冲带 / 飞地 |
| 战争 / 军事 | 战略要冲 / 后勤线 / 屏障 / 关隘 / 港口 |
| 悬疑 / 探案 | 案发坐标 / 嫌疑人活动半径 / 监控盲区 / 物证流向 |
| 克苏鲁 / 末日 | 禁忌带 / 异常区 / 安全屋 / 接触点 / 隔离带 |
| 言情 / 都市 | 主角活动半径 / 相遇地 / 工作地 / 家 / 共同记忆地点 |
| 脑洞 / 末世 | 适应区 / 异变区 / 变种带 / 生存据点 / 资源点 |

### 1.4 验收清单（FAIL → 门 1 BLOCK）

- [ ] 总览 4 项全部填写（不允许"待定"占位）
- [ ] 核心区域数量 ≥ 题材最低要求
- [ ] 每个区域**必有**一个"叙事功能"字段（不能是"待用"）
- [ ] 流动路径至少 2 类已填，禁区必填
- [ ] 地图与剧情对应至少 4 个有效条目
- [ ] 题材特化字段按 §1.3 全部填完
- [ ] 任意章节卡 / 场景骨架引用的地点，必须在 world-map 中存在
- [ ] world-map 修改时同步更新 Canon 事实表与时间线相关事件

## 二、宇宙地图输出约定（universe-map）

### 2.1 触发条件

| 项目类型 | universe-map 必备级别 |
|---------|---------------------|
| 单世界故事 | ⚪ 不建（不适用） |
| 多界 / 跨位面 | 🔴 必建 |
| 星海科幻 | 🔴 必建 |
| 神话 / 多神域 | 🔴 必建 |
| 无限流 | 🔴 必建（副本宇宙） |
| 玄幻仙侠（涉及多界 / 仙界 / 神域） | 🔴 必建 |
| 平行世界 / 时间循环 | 🔴 必建 |

### 2.2 必填字段

| 字段类 | 字段 | 最低要求 |
|--------|------|---------|
| **宇宙版图** | 宇宙名称 / 世界数量级 / 可观测范围 / 不可观测或禁入区 | 全部填 |
| **核心节点** | 至少 3 个节点，每节点含：层级 / 功能 / 支配势力 / 与主角关系 | 多界故事 ≥ 5 节点 |
| **宇宙通路** | 正常 / 高代价 / 战略 / 禁忌 4 类通路 | 至少 3 类已填 |
| **宇宙地图与剧情对应** | 前期边界 / 中期格局 / 终局视野 / 草蛇灰线 4 项 | 全部填，"草蛇灰线"必有 ≥ 1 节点 |

### 2.3 与世界地图的关系

| 关系类型 | 描述 |
|---------|------|
| **嵌套** | 单一世界（world-map）是 universe-map 的某个节点 |
| **入口 / 通路** | universe-map 通路在 world-map 中体现为具体地理点（裂缝 / 入口 / 神坛 / 节点物） |
| **时差** | universe-map 的不同世界**可以**有不同时间流速 → 时间线必须分世界编号 |

**硬规则**：universe-map 修改 → 自动检查：(a) 主角所在世界是否同步更新 world-map；(b) 通路入口在 world-map 是否标注；(c) 时间流速差是否在 timeline 中体现。

### 2.4 验收清单（FAIL → 门 1 BLOCK）

- [ ] 宇宙版图 4 项全部填写
- [ ] 核心节点数 ≥ 题材最低要求
- [ ] 宇宙通路 ≥ 3 类已填
- [ ] 宇宙地图与剧情对应 4 项全部填，"草蛇灰线"≥ 1
- [ ] 主角当前所在世界在 world-map 中已展开
- [ ] 通路入口在 world-map 标注
- [ ] 跨世界事件在 timeline 标"宇宙级"

## 三、时间线输出约定（timeline）

### 3.1 触发条件

| 项目类型 | timeline 必备级别 |
|---------|------------------|
| 任何项目 | 🔴 必建（无论短篇 / 长篇） |
| 时间循环 / 穿越 / 倒叙 | 🔴 必建 + 时间分线表 |
| 多 POV / 多角色独立行动 | 🔴 必建 + 各角色时间轴并列 |
| 多界 / 跨位面 | 🔴 必建 + 时间流速表（每世界一条）|

### 3.2 必填字段

| 字段类 | 字段 | 最低要求 |
|--------|------|---------|
| **基线** | 故事起点时间 / 当前时间位置 / 已经过总时长 | 全部填 |
| **关键事件表** | 时间点 / 事件 / 涉及人物 / 后果 / **地点**（new）/ **来源章节**（new）/ **类型**（new）| 每事件必有"地点"字段，且地点必须在 world-map 中存在 |
| **时间风险** | 角色行动冲突 / 伤病成长所需时长 / 事件不可颠倒序 | 至少 3 条 |

### 3.3 事件分级（type 字段枚举）

| 级别 | 标记 | 触发记录条件 |
|------|------|------------|
| **canon** | 🔴 不可改 | Canon 事实表已锁定的事件 |
| **major** | 🟠 主线推进 | 影响主角动机 / 局势 / 阶段目标的事件 |
| **subplot** | 🟡 支线推进 | 支线 / 配角 / 群像独立线事件 |
| **background** | ⚪ 背景设定 | 历史 / 传说 / 未在正文出现但已经发生的事件 |
| **future** | 🔵 预告 | 将要发生但未发生的事件（含伏笔回收日程） |

**规则**：
- canon + major 事件**必须**全部录入，不允许遗漏
- subplot 事件按章节回写时录入
- background 事件可在世界观阶段一次性录完
- future 事件用于伏笔调度（见 SKILL-reference §伏笔调度系统）

### 3.4 与章节的硬绑定

每章正文写完，门 5 回写时**必须**：

1. 提取本章发生的所有事件，按 §3.3 分级录入 timeline
2. 每个事件的"地点"字段必须在 world-map 已存在；不存在 → world-map 同步加点
3. 每个事件的"来源章节"字段填本章章号
4. 涉及多 POV 时，每个 POV 视角的事件按"角色独立时间轴"分别录入

### 3.5 多 POV / 多界 / 时间循环 特殊规则

| 场景 | 规则 |
|------|------|
| **多 POV** | 每 POV 一条时间轴，事件交叉处用"同步点"标注 |
| **多界 + 时间流速差** | 每世界一条时间轴，事件穿越时标"流速换算 X:Y" |
| **时间循环** | 用"循环编号 + 循环内时间"双坐标，每次循环重置但累计差异保留 |
| **倒叙 / 闪回** | 在 timeline 中按真实时间线录入，正文叙事顺序在"来源章节"字段标注 |

### 3.6 验收清单（FAIL → 门 1 BLOCK）

- [ ] 基线 3 项全部填写
- [ ] 关键事件 ≥ 5 个（短篇）/ ≥ 章节数 × 2（长篇）
- [ ] 每个事件的"地点"字段在 world-map 中存在
- [ ] canon + major 事件**零遗漏**
- [ ] 每章回写时本章事件已同步录入
- [ ] 多 POV / 多界 / 时间循环按 §3.5 规则录入

## 四、三者联动闭环（world-map ↔ universe-map ↔ timeline）

### 4.1 事件 → 地点绑定

```
timeline 事件
  → 必有"地点"字段
  → 地点必须在 world-map 区域 / 节点中存在
  → 多界事件还需在 universe-map 中存在
  → 否则：Canon 冲突 → 门 4 BLOCK
```

### 4.2 修改传播协议

**任意一方修改时，另两方同步检查**：

| 修改方 | 必须同步检查 |
|--------|-------------|
| world-map 区域调整 | (a) timeline 中涉及该区域的事件是否仍成立；(b) Canon 事实表中该区域设定是否一致 |
| universe-map 节点调整 | (a) 主角所在世界 world-map 是否同步；(b) 跨界事件 timeline 是否仍成立；(c) 通路入口在 world-map 是否标注 |
| timeline 事件改动 | (a) 涉及地点是否在 world-map / universe-map 存在；(b) Canon 中事件描述是否一致；(c) 章节卡 / 章节摘要是否需要回修 |

修改任意一方时，门 5 回写自动触发"传播检查"。漏检 → Canon 冲突 → 下一章门 1 BLOCK。

### 4.3 信息流方向

```
设定阶段：worldbuilding → world-rules → world-map → universe-map（按需）
状态阶段：world-map / universe-map ⇄ timeline ⇄ canon-facts
正文阶段：章节卡引用 world-map 地点 + timeline 时间锚点 → 正文
回写阶段：正文新事件 → timeline 录入 → 必要时反哺 world-map / universe-map / canon
```
